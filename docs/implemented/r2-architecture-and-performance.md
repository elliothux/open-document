# R2 架构精简、核心下沉与性能重构

状态：`implemented`。2026-11-11 完成。公开入口、核心职责和宿主边界归 [SDK 合同](../references/sdk.md)。

## 交付结果

| 批次 | 已实现 |
| --- | --- |
| R2.1 核心缓存 | DOCX 复用已解析文档流，XLSX 复用关系、绘图及便笺和线程部件，PDF 复用页面解释和有界绘制编码。缓存按文档版本、候选状态及适用字体映射失效。 |
| R2.2 命令与校验 | DOCX、XLSX 统一用 `execute(command)`。四格式 Bridge 用类型化请求和查表分发。宿主共用 Worker 生命周期、命令队列和图片缓存。核心提供输入限额及响应结构，保存前校验变更部件。 |
| R2.3 渲染与图像 | 核心给出裁剪、描边、字形及图像采样策略，Canvas 按设备坐标绘制。支持的 PNG/JPEG 由核心解析和解码。其余资源走宿主解码并保留原压缩字节。 |
| R2.4 响应与传输 | 合并编辑状态、光标与选区。字形轮廓和图表绘制按会话增量传输。PDF 合并连续文字，XLSX 压缩网格线指令。文件和资源用字节槽与可转移缓冲区传输。 |
| R2.5 排版与计算 | DOCX 按段落版本、可用宽度和字体映射复用测量，并缓存独立分节的分页结果。XLSX 使用强类型坐标与区间依赖索引，按版本缓存条件格式统计和图表绘制。 |
| R2.6 Wasm 与字体 | 提供全格式和四份单格式 Wasm。实例内按字体字节共享解析结果与基础字形，文档继续拥有独立会话、字体别名和预算。 |
| R2.7 文档与证据 | 按格式拆分合同，归档历史批次。兼容性证据表从私有账本生成。入口见[格式目录](../references/formats.md)和[测试说明](../references/testing.md)。 |

相对 C0 构建 `381c144d`，四格式、共享宿主及 Wasm 包的 TypeScript 源码由 82,257 行降到 75,523 行。MoonBit Bridge 由 9,667 行增至 14,138 行。统计包含工作树内相关改动。

## 性能与发布产物

在 arm64、Node 26.13.0 上，用构建 `37258651…` 和固定 C0 原件测量 Wasm 热调用中位数。三份原件的绘制指纹、响应大小和原样保存字节与登记基线一致。

| 原件与操作 | 实测 | R2 门槛 |
| --- | ---: | ---: |
| DOCX LinkedTextBoxes 重复布局 | 10.73 ms | 50 ms |
| XLSX 19 图表工作簿重复视口 | 2.22 ms | 20 ms |
| PDF tracemonkey 重复渲染 | 0.065 ms | 10 ms |

19 图表工作簿在另一固定构建 `3bd39b83…` 的五个滚动位置中位数为 8.73 ms。ABI 18 固定构建的 tracemonkey 前四页各有 25–629 条顶层指令，首次响应为 0.73–1.10 MB。DOCX 一次按键使用两条 Worker 消息。

构建 `37258651…` 的五份 Wasm 均低于 8 MiB。全格式为 8,201,033 字节。DOCX、XLSX、PPTX、PDF 分别为 4,487,890、3,962,457、3,787,292 和 5,776,024 字节。七个发布归档的安装和消费检查在 `bec9a24b…` 通过。共享字体的固定探针中，Noto Sans SC 原生注册中位数从 102.79 ms 降至 0.28 ms。

## 三、兼容矩阵覆盖审计

构建 `37258651…` 通过 `bun run check` 和全部 2,098 项登记核心用例。Chromium 共核对 987 条用例。其中 906 条在该构建通过，81 条沿用 `ffe58844…` 的通过记录。后者还通过 158 项单元检查。每份报告均记录构建身份。

复核发现局部裁剪误收设备像素对齐标记。核心将标记限定于首个裁剪覆盖整页的区域。修复后，PDF 原件和三种 XLSX 面积图打印的独立像素差异均为 0/0。XLSX 切片器用例首次未观察到第二次选择提交，原用例重跑通过，首轮记录已保留。

详细证据归私有 `cases/r2-architecture.json` 和 `cases/r2-performance.json`。四格式的无浏览器核心闭环见 [P16.1](../p16-cross-host-runtime.md)。新增语料、多生产工具及分级降级归 [C1](../c1-corpus-and-producer-compatibility.md)。支持范围以[兼容性矩阵](../references/compatibility.md)为准。
