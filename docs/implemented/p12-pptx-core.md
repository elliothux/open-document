# P12 PPTX 核心功能

状态：`implemented`。五批最低交付范围已接通核心、同步 Wasm/Worker SDK、默认 UI、历史及保存输出。基于 [P6](p6-pptx-editing.md)、[P9](p9-web-sdk-ui.md)及共享包事务。当前 API、原生资源和预算归[格式合同](../references/formats.md#pptx)，功能差距归 [G3](../g3-genoffice-sdk-gap.md#演示pptx)，后续归[路线图](../references/roadmap.md)。

## 已交付结果

| 批次 | 用户操作 |
| --- | --- |
| 文稿与对象 | 空白文稿；页增删/复制/重排/隐藏和章节；对象插入/删除/复制、多选、移动/缩放/旋转/翻转、对齐/分布、组合/取消组合及层次 |
| 文字与页面 | 字符/段落/项目符号、查找替换、框内边距/垂直锚定/自动适配；页面尺寸/背景、主题、版式/母版及受支持占位符；基础形状样式及图片插入/替换/裁剪/透明度 |
| 复合内容 | 表格/行列/合并/样式；常用二维图表和嵌入数据；流程/层级/循环形状组图示、基础数学/艺术字；对象/文字链接及动作、备注/本地批注、日期/页码/页脚 |
| 放映与媒体 | 基础放映与同页演讲者界面、导航和临时画笔；音视频插入/播放；直接/淡入淡出/推入切换，出现/消失、淡入淡出、飞行、缩放/旋转和线性路径及顺序/触发/计时 |
| 文件与输出 | 插入其他 PPTX 的受支持页面和资源；原格式保存、当前/全页 PNG/JPEG、静态 PDF 与浏览器打印 |

共享图表包含普通及堆积/百分比堆积折线，编辑嵌入数据、复制及保存后继续沿原生图表工作。简化 SmartArt 是可编辑形状组及连接线，不是原生 diagram 编辑器。媒体已在 Chromium 检查 PCM WAV 与 VP8 WebM，编码能力依宿主；外部资源不自动下载。

## 实现与完整性

文稿、对象/组坐标、版式继承、原生资源及播放状态由 `modules/formats/src/pptx/` 拥有。Web 只负责平台事件、帧调度、媒体设备与资源释放。放映基于已提交修订，使用有界逻辑时间与核心显示状态；静态输出沿 [R0](r0-renderer-foundation.md)，不推进动画或保存临时播放状态。

页面和对象使用稳定身份；复制、组合、导入与删除维护已支持的关系和资源，候选不改源，一次提交一项可精确撤销的历史。未知可见对象保持点穿保护，不能通过删除未知内容开放操作。具体代码入口与写回合同在[格式说明](../references/formats.md)维护。

## 检查与边界

所改操作使用定向核心、严格接口及 Chromium 流程检查原生输入、真实指针/播放、精确历史、失败恢复、原生 XML、保存重开及对应 Canvas/PDF/图片。最近堆积折线沿三个格式共用核心和图表合同，检查累计/比例、默认控件、复制、历史和输出；既有面积图回归通过。公开 api/check/build 通过。详细证据归[测试说明](../references/testing.md)及私有 `stackedLineCheckpoint`，复用未改变路径的通过结果。

原生 SmartArt、任意自定义几何、跨父容器连接、复杂效果/动画/媒体计时、东亚直排和长尾继承/适配/导入变体归 P14。3D、AI、协作、Diff 与跨窗口演讲者扩展归 P15/P16。静态 PDF/图片使用媒体封面和已提交完整内容，不能承载可播放媒体。未执行全量套件、外部 PowerPoint 或其他浏览器验收。
