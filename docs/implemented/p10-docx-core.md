# P10 DOCX 核心功能

状态：`implemented`。六批最低交付范围已接通核心、同步 Wasm/Worker SDK、默认 UI、历史及保存输出。实现从 [P4](p4-docx-editing.md) 和 [P9](p9-web-sdk-ui.md) 扩展；阶段范围不包含完整 Word 兼容。当前 API、原生字段、保护与预算归[格式合同](../references/formats.md#p10-当前格式编辑)，功能差距归 [G3](../g3-genoffice-sdk-gap.md#文档docx)；后续归[路线图](../references/roadmap.md)。

## 已交付结果

| 批次 | 用户操作 |
| --- | --- |
| 创建与格式 | 空白 DOCX、另存、字符/段落格式、混合状态、格式复制/清除、样式管理、主题颜色/字体、普通/多级列表、查找替换 |
| 页面与表格 | 页面/节/栏、分页与页码、普通首页/奇偶页页眉页脚；表格创建、行列编辑、合并/拆分、跨格选择、拆表、宽高/边距/对齐、边框/底色、重复表头及跨页续排 |
| 图文与片段 | 图片插入/替换/删除/裁剪、行内与受支持浮动环绕；基础形状/文本框/艺术字、层次、原生富文本及 HTML/Markdown 粘贴；基础封面、背景、水印、页面边框和墨迹 |
| 引用与审阅 | 链接/书签、目录/字段/交叉引用、脚注/尾注、题注/索引、引文/书目；本地批注/回复、修订记录与接受/拒绝、编辑保护、标题导航/标尺/统计 |
| 图表与数学 | 常用二维柱/条、折线、饼、面积及散点图和嵌入数据；分数、上下标、根式、括号、求和/积分、矩阵等基础 OMML、已映射 LaTeX 和符号输入 |
| 保存与输出 | 原格式保存、同布局 PDF、逐页 PNG、HTML/Markdown 与浏览器打印；输出与原格式保存状态分开 |

脚注与尾注支持多段内容、节/文档位置和节编号属性。脚注逐页重启按实际物理页及正文顺序计算，兼顾多栏、表格引用、续排和 NOTEREF。字段和编号是核心派生结果，原生源、格式、精确历史及保存重开共用事务。

## 实现与完整性

状态、内容与原生写回由 `modules/formats/src/docx/` 拥有，分页和图元由 `modules/layout/src/` 拥有。R1 后，严格类型入口、Worker/平台事件和领域界面归 `packages/docx/`，共用绘制与外壳归 `packages/web-core/`、`packages/ui/`，复用 [R0](r0-renderer-foundation.md)。多部件事务一起维护关系、内容类型、资源和选择，失败保持源与历史。

本阶段的源代码归属和精确接口在[格式合同](../references/formats.md)维护。安全/未知源保护、字体预检、资源及历史上限继续生效；不通过丢弃原生内容开放编辑。

## 检查与边界

按受影响用户流程执行定向核心、接口及 Chromium 检查，覆盖原生输入、候选/取消、精确历史、失败恢复、保存重开和独立 XML/PDF；复用已通过且路径未改变的结果。最近的脚注/尾注位置、节编号和逐页编号已有核心、默认控件、布局及输出证据。公开 api/check/build 通过。详细记录归[测试说明](../references/testing.md)、私有 `p10-docx-core.json` 及 `pageNoteNumberingCheckpoint`。

支持范围以格式合同为准。复杂嵌套/浮动表格、其他对象容器、长尾字段/数学/装饰、整套主题导入、旧格式和加密继续按 P14 扩展。AI、Diff、协作、校对和 Zotero 归 P15。HTML/Markdown 是已支持语义与对象的交换输出，完整页面外观使用同布局 PDF/PNG。未执行全量套件、外部 Office 或其他浏览器验收。
