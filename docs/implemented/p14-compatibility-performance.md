## 性能结果

P14.P1 优化 DOCX 首次布局。共享布局核心复用同一行在测宽后立即绘制时的塑形结果，仅保留一项。下一次塑形调用消费或失效该结果；字体加载、错误和关闭会清理它。字体回退、诊断、轮廓和最终几何仍执行原有检查。

2026-10-29，在同机 Linux x64、固定 CPU 4、Node 24.21.0 下测量公开核心调用及 JSON 桥接。A、B 使用相同冻结 JS 桥接、不同发布 Wasm。`--no-liftoff --no-wasm-lazy-compilation` 在计时前完成优化编译，`--expose-gc` 在样本间回收；初始化、独立检查及回收均在计时区间外。

每侧 5 次预热，20 对 A/A 校准后冻结噪声和回退预算，再交替 AB/BA 采集 20 对。五项校准均可靠，450 个样本的布局、保存、历史与重开检查全部通过。

| 操作 | A 中位数 | B 中位数 | 判定 |
| --- | --- | --- | --- |
| 4096 字符、17 页首次布局 | 56.91 ms | 40.07 ms | 降低 29.6%；16.84 ms 降幅超过 8.43 ms 校准噪声 |
| 同输入重复布局 | 11.98 ms | 13.21 ms | `within-budget` |
| 同输入 PDF 导出 | 49.84 ms | 57.13 ms | `within-budget` |
| 既有 P4 输入首部编辑 | 3.22 ms | 3.04 ms | `within-budget` |
| 既有 P4 输入尾部编辑 | 2.09 ms | 2.16 ms | `within-budget` |

回退预算沿用既有算法，未按结果调整。未提速的字体映射候选和校准不可靠的尝试完整保留。以上仅说明已就绪 Node 核心调用；浏览器输入延迟、启动耗时及 JS heap、RSS、WasmGC 峰值未测量。
