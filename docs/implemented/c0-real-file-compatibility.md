状态：`implemented`，2026-11-07。首批 51 份固定候选已完成登记范围。48 份正向输入通过，3 份控制按预期拒绝。四格式的 128 条登记浏览器流程全部通过。

## 用户结果与范围

用户能在 Chrome/Chromium 中打开这批 DOCX、XLSX、PPTX 和 PDF，查看声明内容，完成登记编辑，并保存重开。只读、受保护和未知特性继续按[格式合同](../references/formats.md)处理。通过本批不代表任意 Office 或 PDF 变体均已支持。

PPTX 已补齐母版与版式继承、占位符、SmartArt 缓存、表格、原生媒体和 WMF 的登记流程。C13 采用用户批准的完整独立参考，恢复原图 RGB、透明组和适当采样。130 组严格比较均为 0/0，源部件、精确历史和新 Worker 重开通过。

PDF 已补齐本批字体、图片解码、颜色、图层、透明、渐变、表单与批注流程，并支持声明的加密、PDF 2.0 只读和有限交叉引用恢复。C17 的 14 页及旋转共 28 组整页比较均为 0/0。固定 Poppler 参考工具包含通用缓存范围守卫；原件和 SDK 阈值保持。

DOCX 的双栏、浮动图片、字段、链接文本框、内嵌预览、VML 和登记加密原件通过对应显示、编辑或只读保存流程。实际权限和排版边界归[格式合同](../references/formats.md)。

XLSX 已补齐本批数字格式、绘图、条件格式、透视刷新、Strict 读取及手工计算。C43 的 19 张原生图表均可显示。原始工作表 15 页的 Canvas/PDF 共 30 组、重算后全部可见页的 32 组严格比较均为 0/0。104 个非随机值、26 个 RAND 的数值范围、图表缓存、精确历史及新 Worker 重开分别检查。

C43 按用户选择跟随固定 ONLYOFFICE 10.0 外观，包括复合饼图显示为普通饼图、气泡图显示为散点等降级。原始数据、尺寸、拆分定义和其他源属性完整保留。两张气泡图按相同的 62% 或 65% 倍率分别验收，全部整页断言保持。

## 实现归属

MoonBit 负责格式读取、状态、编辑、布局、计算和序列化。TypeScript 继续负责平台事件、Worker 和图元执行。原生图表沿 ONLYOFFICE 的独立参考行为修复，共用曲线、投影、色带、文字和描边能力。普通 Canvas 的填充直线多边形复用既有有界描边策略。

最终图表修复包括单曲线扇区的打印底纹规则、原生标签位置、零长线段省略、曲面轴端裁边、精确色带顶点和相邻直线的独立路径。产品代码不识别测试文件，也不通过放宽断言取得通过。实现边界归[工作表图表](../references/formats/xlsx-objects.md#工作表图表)。
