# P4 DOCX 编辑与保真保存

状态：planned。已有编辑代码与测试切片，完整功能交付尚未确认。项目未发布，当前有 0 个用户。

## 当前目标：功能优先

交付一个可嵌入的 DOCX 编辑入口，让开发者用真实文件完成打开、选择、输入、删除、拆合段、撤销、剪贴板、保存重开和 PDF 输出。每次选其中一个具体操作，确认输入与期望结果，修复缺口并给出操作方式和输出文件。

以可操作功能和输出作为进度。未发布 API 和模型沿单一路径直接修改；迁移、发布和性能专项留待后续。每次变更保持文档保真、错误恢复、安全上限、键盘操作和焦点语义。

## 1. 用户结果与范围

当前覆盖 Chrome/Chromium 中的普通正文和单个表格单元格内的纯文本编辑：

- 点击/拖动选区、按字素移动光标、Shift 扩选。
- 输入、替换、删除，跨文字 run 和相邻普通段落编辑。
- Enter 拆段、Backspace/Delete 合段、撤销/重做。
- 普通输入法组合、纯文本复制/剪切/粘贴。
- 保存 DOCX，重新打开并保持正文、格式和非目标内容；从当前布局导出 PDF。

暂不做完整 Word UI、跨单元格编辑、表格结构修改、图片插入、富 HTML/RTF 粘贴、复杂修订/批注/字段更新、浮动对象、移动端或协作。不能安全修改的区域明确拒绝；只读保护不代替正向编辑交付。

系统输入沿用现有输入法，不切换系统设置。Windows/Word 与 VoiceOver 验收跳过。

## 3. 实现合同

MoonBit 核心拥有文档、选区、历史、布局和序列化。TypeScript 接入平台事件、Worker、生命周期与 Canvas，使用核心提供的状态和塑形结果。

### 3.1 文档状态与源内容保留

源 XML/OPC 是文档权威。修改仅作用于目标范围，保留其他部件、未知内容和范围外样式。书签、字段、内容控件、图片及无法安全解释的结构不能被范围编辑静默删除。

命令校验 revision；布局查询校验 layoutId。错误返回时正文、历史和有效状态不发生半提交。成功保存后由独立 ZIP/XML 检查目标变化与非目标保留；SDK 重开和参考应用重开分别判断。

### 3.2 位置、选区与命中

位置使用逻辑 UTF-16 offset，移动和编辑保持代理对与字素完整。核心从实际 shaping、BiDi 和字体 GDEF/回退度量生成光标、选区及命中坐标，宿主使用这些坐标。

左右按逻辑字素导航，Shift 保留 anchor。非折叠选区下 Left 收拢到起点，Right 按用户决定从末端再前进一个字素；文档末端保持边界。上下移动保留目标 x；Home/End、软换行两侧和 BiDi 到达位置按当前格式合同实现。

`frameStart`、`bidiLevel` 等派生信息用于还原视觉光标，不改变真实逻辑编辑位置。过期布局、非法坐标和受保护区域返回明确错误，不能误编辑相邻内容。

### 3.3 命令、事务与历史

一个编辑动作原子提交。普通连续输入可合并撤销组；导航、删除、Enter、失焦、保存与错误恢复形成边界。撤销/重做精确还原源内容和选区。

保留既有历史、输入和队列上限。超限拒绝并保持可恢复状态；外部 revision 冲突不能强制撤销未知更改。完整数值和错误身份归[格式合同](references/formats.md)，不在本方案重复维护。

### 3.4 输入、异步与保存

组合输入使用核心 begin/update/commit/cancel 状态；候选更新不创建已提交 revision 或历史，完整提交只发生一次。宿主合并未发送的候选更新，不丢弃已接受输入；尾随通知不能造成重复插入。

纯文本剪贴板将 CRLF/CR 统一为 LF，一次粘贴形成一个事务。权限失败、旧选区、关闭或冲突不能删除原内容。富文本格式不在本期范围。

客户端串行发送命令。保存/PDF 是队列屏障，绑定接受输入后的 revision 和布局。关闭等待已接受工作，释放后不再绘制；调用方拥有客户端生命周期。失败时停止后续修改，提供明确恢复路径。

普通 POI 正文中的无子列单栏声明和未启用网格不应误判为复杂布局；未知属性和真实多栏/网格继续保护。

### 3.5 排版失效与性能路径

内容、字体或页面/profile 变化时正确失效布局。已有缓存只复用依赖一致的结果；失败不提交候选缓存，关闭释放，返回结果不能修改内部缓存。

本期复用现有排版路径，修复影响功能正确性或实际可用性的缺陷。复用规则和预算以格式合同为准，进一步优化留在后续。

## 4. 实施顺序与每步交付

1. 用真实可编辑文件验证打开、输入、撤销和保存重开，修通最短链。
2. 补选择、跨 run/普通段落替换、拆合段及受保护范围拒绝。
3. 补键盘、普通输入法、纯文本剪贴板和异步错误恢复。
4. 核对编辑后预览/PDF、非目标保留与关闭释放，给出可操作入口和已知限制。

已有实现、测试入口和适用结果直接复用。每步完成其风险需要的检查后，交付可操作结果，再进入下一项。

完成条件是范围内真实文件可以从嵌入入口完成打开、编辑、撤销、剪贴板、保存重开和 PDF，并保留非目标内容。关键拒绝、失败恢复和关闭路径有对应检查，限制明确。

按[测试说明](references/testing.md)选择足够的最小检查，通过后交付入口、操作、输出与具体缺口。出现新变更、失败或未解决疑点时再扩大验证；功能里程碑或具体跨模块风险需要时运行完整入口。
