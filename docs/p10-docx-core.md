# P10 DOCX 核心功能

状态：`planned`，第 1 批实施中。依赖已完成的 [P9 Web SDK 与默认 UI](implemented/p9-web-sdk-ui.md)，属于功能优先级 P0。已接通空白创建和另存；其余创作能力仍按下面的范围实施。阶段顺序归[路线图](references/roadmap.md)，当前 API 与限制归[格式合同](references/formats.md)，功能依据归 [G3](g3-genoffice-sdk-gap.md#文档docx)。

当前进度：ZIP/OPC 已支持显式创建，以及一次保存中的新增、替换和删除。DOCX 已接通空白创建、首次保存与另存。字体、字号、颜色、粗斜体、单下划线、删除线、高亮和上下标，以及段落左右/居中/两端对齐、缩进、段前后距、行距、段前分页已有核心/API/UI、混合查询、清除直接属性与历史。装饰不拆开塑形，上下标参与字号、基线与选区计算；预览与 PDF 使用相同绘制结果。软换行与 Tab 已接入逻辑位置、格式、删除、历史和保存；Tab 支持文档默认间隔和左/右/居中/小数点自定义位置，包含属性继承、显式清除与历史；文档默认间隔也可修改或恢复，表格原生 Tab 移动到相邻单元格，参数面板保持焦点切换。折叠处的格式随实际输入一起提交，取消组合保留输入格式。字面查找、大小写/全词选项、结果定位、单项和全部替换已接通同一队列，旧结果拒绝且不停止编辑。格式复制已通过核心属性片段接通 API/UI，两类格式合为一次历史；混合属性不覆盖目标。竖线与五类引导线也已接通相同格式事务、核心绘制与 PDF；引导线不进入逻辑文字。RTL 段落方向、制表原点、缩进、对齐与竖线已接入核心、API、UI、历史和输出。标尺、其他内置样式重置规则、主题及后续批次仍未完成，不标记第 1 批或整个 P10 完成。实际签名与边界归[格式合同](references/formats.md#p10-当前格式编辑)。

现有段落与字符样式目录、应用、清除、修改，以及基于现有样式新建和删除自定义样式，已接通核心、API 和默认 UI。它们支持继承、混合查询、撤销和保存重开。应用段落样式时清除段落直接属性；字符样式保留文字直接字符格式。折叠处的字符样式随后续输入提交历史。新建文档提供 Emphasis 和 Strong 字符样式。缺少样式部件的导入文件也能创建首个样式，部件、关系与内容类型合为一次历史。样式管理使用正文与其他 Word XML 的同一历史，保留直接覆盖和未改源内容；删除会同步映射样式引用。默认 UI 当前提供名称、基础样式及全部已支持的字符/段落属性修改，以及从所选样式派生或无基础创建、显式选择同类型替代样式后删除。无基础样式的自定义样式也可删除；没有替代项时保持禁用。属性修改区分保持、设置与恢复继承，确认后合为一项历史。默认段落/字符样式及 Normal、DefaultParagraphFont、Strong、Emphasis 已支持显式格式重置，保留身份、名称与正文直接覆盖。链接自定义样式可删除，对端保留并解除链接。共享样式修改先校验继承编号，失败保留原包。其他内置样式重置规则仍待实现。

已接入已有列表的编号读取和标记排版：七类常用格式、九级计数、样式继承、父级重启与起始覆盖，正文和表格按源顺序计算。标记与正文位置分离，预览、PDF 和页面文字使用相同结果。列表创建、应用、移除、级别调整与重启已接通核心/API/UI、单项历史及保存重开。非空 Enter 延续列表，空项 Enter 退出或降级，段首 Backspace 按级别降级或退出。选区删除和空项 Enter 合为一次历史，粘贴换行保持结构输入。列表 Tab 已接入首项定义缩进、后续项与选择的层级调整、混合段落缩进，以及字面 Tab 与表格导航分流；编号级别覆盖、重启和命名空间一起保存。自定义级别的格式、模板、起点、父级重启、对齐、后缀、缩进和标记字符属性也已接通 API/UI、单项历史及保存重开，正文源内容不变。具体边界归[格式合同](references/formats.md#列表读取与标记排版)。

单节文档的页面尺寸、方向和四边距已接通核心、API、默认 UI、单项历史和保存重开，作为第 2 批的首项。缺少节属性时原子创建，正文与其他部件保留；方向改变由核心旋转尺寸和边距。页面查询返回源尺寸，预览/PDF 继续采用原有纸型解释规则，不把显示尺寸写回源文档。正文手动分页符已接入范围编辑、格式、查找替换、组合候选与历史；默认 UI 按钮及 Ctrl/Cmd+Enter 使用同一事务。相邻分页符保留既定合并规则，每个源节点仍保存，前后光标可定位。表格内手动分页、多节、分栏、页码、页眉页脚及其余表格编辑仍未完成。合同归[页面设置](references/formats.md#页面设置)及[格式编辑](references/formats.md#p10-当前格式编辑)。

正文表格创建、行列增删、矩形合并、取消合并及按当前行拆表已接通核心、API 和默认 UI。核心按可用页宽生成等宽固定网格，复制插入处的字符与段落格式并清除单元格缩进。范围删除、段落拆分与表格插入合为一次历史，选区进入首格。新增行列复制相邻格格式，固定宽表格按比例调整列宽；末格 Tab 自动追加行。删除末行或末列时移除表格，光标进入正文。合并按行优先顺序保留内容与格式，取消合并恢复原网格并将内容留在首格；横向跨度与纵向延续参与布局、边框、底色、Tab 及分页缓存。拆表保留原有行与非空内容的身份，在两表间插入空段落；跨分界线的纵向合并将内容留在上表，下表创建同格式的空合并格。结构、列宽和选择共同撤销/重做，保留未删文字与其他部件。单元格输入、保存重开和同布局 PDF 复用已有路径；首格段前分页随结构转移。整表宽度与当前行最小高度已接通核心、尺寸查询、API 和默认 UI；宽度按原比例同步列网格及合并格，高度支持至少值和恢复自动，沿同一历史保存重开与 PDF。当前格纯色底色与清除也已接通，纵向合并节点同步，自动文字/编号随背景求色。单格顶部/居中/底部对齐已接通样式继承、API、默认 UI、合并行组排版及空白区域命中，预览/光标/选区与 PDF 共用位移。单格四边边距与恢复继承已接通核心、API 和默认 UI，非对称边距及同行顶部最大值参与相同排版、缓存和 PDF。整表左/中/右对齐与默认四边边距编辑已接通，分别查询表格默认值与当前格有效值，保留单格覆盖和精确历史。任意行列数拆格、鼠标跨格选择、含合并格的行列编辑、精确行高/单列宽、自动适配、跨页合并延续与其余属性修改仍待实现。合同归[表格创建](references/formats.md#表格创建)。

## 1. 用户结果与交付范围

用户能新建文档，编辑文字格式、列表、页面、表格与图文，加入引用和审阅内容，并保存为可继续编辑的 DOCX。相同操作同时通过程序化 API 和默认 UI 提供。GenOffice 源码定义功能与交互目标；Office 语义、布局和算法优先参考 ONLYOFFICE，其次 LibreOffice。

P10 分批交付，每批包含核心、API、UI、历史与保存。第一批可独立使用，但不代表整个 P10 完成。

| 批次 | 用户操作及最低交付范围 | G3 对应 |
| --- | --- | --- |
| 1. 新建与格式编辑 | 空白 DOCX、另存、软换行/制表符、字符格式、段落格式、选区混合状态、格式清除/复制、样式应用与新建/修改/删除、主题字体/颜色、普通与多级列表；查找替换 | D01–D06、D22 |
| 2. 页面与表格 | 页面尺寸/方向/边距、分页/分节/分栏、页码；首页/奇偶页页眉页脚；表格创建、行列增删、合并拆分、跨格选择、拆表、宽高、边框底色与重复表头 | D07–D10 |
| 3. 图文与剪贴板 | 图片创建/替换/删除/裁剪、内联与浮动环绕；形状/文本框、基础艺术字、层次；富文本片段与 HTML/Markdown 粘贴；封面、背景、水印、页面边框与墨迹 | D02、D11、D12、D21 |
| 4. 引用与审阅 | 链接/书签、目录/字段/交叉引用、脚注/尾注/题注/索引/引文书目；批注/回复、修订记录与接受/拒绝、编辑保护；标题导航、标尺和字数 | D15–D19、D22、D23 |
| 5. 图表与公式 | 常用二维图表及嵌入数据编辑；基础数学表达式输入、OMML 存储与数学排版、符号插入 | D13、D14 |

复杂嵌套/浮动表格、长尾字段与数学排版、历史格式和加密属于 P14；本阶段创建的分栏、表格、浮动对象和字段必须能编辑、显示、保存。Diff、AI、协作、校对和 Zotero 属于 P15。缺失功能仍留在 G3，不能以“源内容保留”记为已交付。

## 3. 第一批的实现设计

### 3.1 新建与多部件事务

先为核心 ZIP/OPC 补两项实际能力：从显式部件集合创建包；在源包中原子新增、替换和删除部件。复用现有路径、XML、解压与输出预算。检查同名冲突、内容类型、关系目标、外链标记和签名限制，保留未改部件的源内容。现有替换保存直接改用扩展后的单一路径，不保留旧实现分支。

DOCX 创建入口生成最小合法包：根关系、主文档、所需样式/设置、内容类型及一个空段落。编号、图片、页眉页脚等部件按实际操作创建。模板由 MoonBit 的格式代码生成，不在 React 中拼 OOXML，也不维护一份只能打开的 base64 空文件。

当前编辑历史已记录正文、样式及其他 Word 部件中样式引用的源片段，并支持首次样式所需的 XML 新增、关系和内容类型，合并校验候选并原子回放。继续扩展一次文档操作涉及的部件变化：已有部件删除、其他对象的关系/内容类型、二进制资源、前后选择及新节点身份。候选全部校验成功后，提交一次 revision 和一项历史。失败保留已提交文档与历史；撤销同时恢复关系、资源和节点身份。

原始包与已提交部件用于保真；类型化样式、段落和对象视图由它们派生。不能另建可独立编辑的 TS 文档树。历史继续有界；新增二进制资源计入资源和历史持有预算，复用不可变字节，不能以只计句柄隐藏内存。仅删除本次操作创建且已确认没有引用的资源；不扫描删除未知部件。

这是 [P11](p11-xlsx-core.md) 和 [P12](p12-pptx-core.md) 复用的包写入能力。它不包含三格式共用的文档事务、位置模型或历史管理器。

### 3.2 格式、范围与输入

延续 UTF-16 offset、字素边界和稳定节点身份。当前位置只有正文段落上下文；进入页眉、脚注等功能时，位置增加所属部件/内容区域。文字范围、表格矩形和对象选择使用可区分的类型，跨内容区域的非法范围明确拒绝。

字符格式操作在核心拆分边界 run，保留范围外属性和未知内容。实现字体、字号、粗斜体、下划线/删除线、文字色/高亮、上下标与清除直接格式。查询区分一致值、混合值和不适用，不能用第一个字符的值代表整个选区。设置、清除和不修改某项属性也必须可区分。

折叠选区改变后续输入属性，不插入空文字伪造文档变化；开始实际输入时与文字一并提交。段落操作明确覆盖被选中的段落，支持对齐、缩进、段前后距、行距、制表位与分页约束。样式修改保持直接格式与继承的区别，检查继承循环；删除被引用样式时显式指定替代样式。

列表使用 numbering 部件的抽象定义、实例、级别和重启规则。编号文字由核心计算与排版，不能把“1.”写进正文来模拟。普通输入、回车、退格与列表降级按 ONLYOFFICE 的对应规则接入现有输入事务。

软换行与段落分隔使用不同的内容节点；Tab 根据正文/表格/输入面板上下文处理。IME 延续已有候选机制，格式菜单不能在组合期间改变其目标。格式刷使用核心返回的属性片段，不复制页面几何。

查找读取逻辑文字，返回绑定 revision 的范围。单次替换与全部替换复用范围事务；全部替换先确定不重叠目标，再一次提交，避免 offset 漂移和部分替换。初期支持字面文本、大小写和全词选项，不前置通用正则执行器。

### 3.3 SDK 与 P9 接入

以下是拟定入口，实施时同步修改桥、Wasm 类型、client、Web 编辑宿主及调用方；不预先发布未实现的空方法。

| 入口 | 最小合同 |
| --- | --- |
| `FoundationSession/Client.createDocx(budget)` | 创建空白会话并返回与打开一致的查询结果；默认页面参数由核心确定 |
| `queryFormatting(revision, selection)` | 返回字符/段落/样式/列表的有效值、混合状态和本操作的限制原因 |
| `setCharacterFormat` / `setParagraphFormat` | 显式 revision、选择和类型明确的属性修改；返回已提交状态 |
| `applyStyle` / 样式和列表操作 | 用稳定身份定位，校验引用与保护；不接受任意 XML 字符串作为编辑协议 |
| `find` / `replaceMatches` | 有界匹配结果、revision 与替换文本；过期结果拒绝 |

Web 编辑宿主在现有队列中补对应方法，默认 UI 使用同一方法。选择属性放入格式状态；全量样式/批注等列表按面板需要查询，React render 不发核心请求。颜色、字体等控件按用户确认提交；拖动预览若确有需求，使用核心候选并在结束时产生一项历史。

P9 的 `mountEditor` 扩展文件输入为“已有 `{ name, bytes }`”或“空白 `{ name, blank: true }`”，以类型联合排除同时传入。实例新增 `create({ name })`，复用 `open` 的草稿/修改确认和独立候选替换。DOCX、XLSX、PPTX 已接通该入口，分别归 P10/P11/P12；PDF 留到 P13。不为未知格式生成占位文件。

新建文件即使尚无编辑，也需要首次保存。P9 当前按 revision 与保存基线判断修改；这里补“尚未持久化的新文档”状态，保存回调成功才清除，下载仍不代表持久化。放弃关闭和晚到保存回执沿 P9 规则处理。

另存使用用户指定的新名称与现有输出/保存回调，存储目标由宿主确定；失败保留原名称和修改状态。故障恢复继续提供已提交状态的保存/恢复副本下载，未提交候选按现有恢复规则处理，不把失败的半成品当成恢复文件。

## 4. 后续批次的关键设计

### 页面、内容区域与表格

节拥有页面参数、栏、页码和页眉页脚引用。核心按内容顺序解析节边界，布局先确定页/栏可用区域，再排段落和表格。页眉页脚的首次/奇偶页及“链接到前一节”属于文档语义；修改共享部件与断开继承是两种明确操作。命中结果带内容区域身份，不能把页眉坐标映射到正文。

表格以逻辑网格计算合并区域和单元格跨度。插入/删除、合并/拆分先计算最终结构与内容去向，再修改 XML；合并涉及多格内容时保留其段落顺序。边框冲突、自动宽度、单元格边距和垂直对齐由核心求值。跨页布局提供重复表头与可拆行的延续状态，行不能无界重试分页。复杂嵌套和浮动表格另入 P14，普通长表不能因此仅支持一页。

### 图片、浮动对象与富文本片段

新增图片同时提交压缩源、关系、内容类型和对象 XML。宿主只提供字节、可用解码结果与资源生命周期；核心确定尺寸、裁剪、锚定、环绕和命中。图片替换保留或显式修改原对象布局属性，失败不遗留空关系。

浮动对象先覆盖矩形/椭圆/线、文本框与常用方形/上下型环绕。布局按锚点放置对象，再把排除区域用于文字断行；移动锚点或对象尺寸要使相关行和后续页失效。复杂轮廓环绕与特殊文字变形归 P14。封面、水印和墨迹复用已实现的页面/图形能力，仍写成可保存对象。

剪贴板片段由核心输出逻辑结构、格式和资源引用。内部粘贴重映射节点、关系和样式身份；跨文档资源随片段有界携带。HTML/Markdown 在导入边界转换为同一片段，再进入核心事务。HTML 只接受声明的元素/属性，移除脚本与事件属性，不发起外链资源请求；保留格式/匹配目标格式/纯文本是明确选项。不能把浏览器 DOM 变成排版权威。

### 引用、审阅与保护

书签、批注、脚注和修订锚点随文字/结构事务更新；删除锚点内容时执行对应的收缩、删除或保护规则。脚注在核心预留页底区域并参与分页，尾注进入相应结尾区域。目录与页码字段先布局、更新结果，再有界重排；不能收敛时给出诊断，保留最后完整结果，不无限循环。

字段先实现 PAGE、NUMPAGES、REF/PAGEREF、SEQ 与标题目录；引文/书目和索引采用可编辑源数据与已实现的格式规则。未知域代码保留且不执行。更新派生结果写回时与相关字段作为一项用户事务，不能让保存偷偷改变正文而不进入状态通知。

批注包含作者、时间、范围和回复关系，作者由宿主显式提供。修订先覆盖文字插入/删除与字符/段落属性；接受/拒绝修改对应源结构，按作者和类型查询。未支持的结构修订保持保护，复杂修订变体归 P14。文档保护在核心校验，UI 禁用不能代替权限判断；未支持的保护算法继续拒绝受保护操作，不移除保护标记绕过限制。

### 图表、数学与输出

图表保存图表部件、系列/轴/样式、嵌入工作簿及关系，系列缓存与数据保持一致。P10 只要求所建图表使用的矩形数据读写；在 XLSX 所属模块补这项内部能力，由 P11 扩展为工作簿编辑，不等待 P11 全部功能，也不在 DOCX 中实现第二个电子表格引擎。

数学结构读取/写回 OMML，核心根据字体度量排上下标、分数、根式与矩阵，输出已有路径/字形。LaTeX 是输入表示，不是无界宏语言；不支持的语法拒绝而非降成不可再编辑的图片。图表/数学只在第二处实际复用时提取共用布局代码。

PDF 继续使用核心布局；图片输出由平台对相同绘制结果编码，分别声明平台依赖。HTML/Markdown 从核心逻辑内容导出，明确表格、浮动、字段等降级，不静默丢弃。打印消费已生成页面/PDF；浏览器负责打印对话框，不负责重新分页。输出只读，不清除原格式未保存状态。

## 5. 布局更新与薄 Renderer

每种命令报告实际影响的内容区域、段落/对象或资源。沿现有段落缓存、稳定点分页和 R0 更新：改字符重排相关段落，改节参数重排相关节，改共享样式按引用确定受影响范围。依赖无法安全收敛时，在既有预算内完整重排；不以不完整的失效信息换取速度。

Renderer 继续消费位置已确定的图元、资源和覆盖层。新增表格、图表、数学和浮动语义放在核心；Web 仅做视口、事件合并、资源准备与像素绘制。按功能消除实际卡死和不可交互，缓存平台、基准矩阵与专项性能门槛留到 P14。
