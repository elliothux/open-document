# P11 XLSX 核心功能

状态：`planned`。基于 [P5 XLSX](implemented/p5-xlsx-editing.md)、已完成的 [P9](implemented/p9-web-sdk-ui.md)及 [P10 的包创建与多部件事务设计](p10-docx-core.md#31-新建与多部件事务)。属于功能优先级 P0，下面的扩展尚未实现。阶段顺序归[路线图](references/roadmap.md)，现有 API 归[格式合同](references/formats.md#p5-xlsx-合同)，功能依据归 [G3](g3-genoffice-sdk-gap.md#表格xlsx)。

## 1. 用户结果与交付范围

用户能新建工作簿，维护工作表与行列，编辑格式和常用公式，排序筛选、建立表格和透视分析，插入图表，并保存和打印。程序化 API 与默认 UI 调用同一核心操作。GenOffice/Univer 集成用于核对功能和 UI；计算、引用变化与文件写回优先参考 ONLYOFFICE，其次 LibreOffice。

| 批次 | 用户操作及最低交付范围 | G3 对应 |
| --- | --- | --- |
| 1. 创建、结构与格式 | 空白工作簿；表增删/改名/复制/移动/隐藏；行列/单元格插入删除与宽高；字符/数字/边框/填充/对齐格式、格式刷、合并/拆分、冻结；公式栏与范围定位 | S01、S03–S05、S09、S21 |
| 2. 计算与范围操作 | 常用函数、名称/引用、重新计算；复制/剪切移动、选择性粘贴、序列/公式填充；查找替换；解除已能证明安全的局部编辑限制 | S02、S06–S09、S24 |
| 3. 数据规则 | 多键排序、值/条件/自定义筛选和重新应用；条件格式；数据验证；结构化表及引用；分列/去重；保护、分组折叠、批注/便笺和链接 | S10–S13、S18–S20 |
| 4. 分析与绘图 | 可刷新透视表、行列/值/筛选字段、常用聚合/分组、切片器与日期时间线；常用图表/迷你图、图片/形状/文本框及其锚点 | S14–S17 |
| 5. 交换与输出 | CSV/TSV 文件导入、CSV 导出；页面设置、打印区域、重复标题、页眉页脚、适合页数缩放与多表打印/PDF | S22、S23 |

基础函数清单见第 4 节。图表沿 P10 的常用二维类型，迷你图先覆盖折线、柱和盈亏。条件格式先覆盖值/公式规则、色阶与数据条；数据验证覆盖数值、日期、长度、列表及公式条件。透视表先使用本工作簿内有界矩形/结构化表数据源，交付计数、求和、平均、最小/最大与日期/数值分组。

结构化表、透视表和绘图既能创建，也能继续编辑符合上述范围的已有文件。复杂导入变体、更广函数/图表、外部数据、旧 XLS/XLSB、加密和大表专项归 P14。快速填充、公式审计工具、AI、协作与 Diff 归 P15。边界不取消核心操作需要的引用完整性和重算能力。

## 3. 创建、结构与格式

### 3.1 文档与事务

空白工作簿由 XLSX 核心生成 workbook、一个可见 sheet、基础 styles、关系和内容类型。复用 P10 的 ZIP/OPC 新增部件能力，接通 P10 扩展后的 P9 新建入口与首次保存状态。文件名不作为工作表身份。

工作表以稳定身份定位，顺序和名称是可变属性。复制/新增分配新的 sheetId、部件路径和关系 ID；移动不改变身份。至少保留一个可见工作表；删除最后可见表、非法名称和名称冲突在核心拒绝。删除活动表后返回新的有效选区。

每项结构操作先形成候选：工作簿/工作表、公式、名称、范围属性、绘图关系、计算结果与选择一起校验，再提交一次 revision/历史。旧历史的工作表索引不能在重排后指向另一张表；改为稳定身份，增删部件也进入同一历史。撤销同时恢复引用、资源和计算状态。

结构操作遍历实际存在的稀疏单元格和区间。整行/整列选择是范围描述，不展开百万个空单元格。操作前检查单元格、公式工作量、历史、资源和输出预算，不能先创建巨大矩阵再报超限。

### 3.2 引用随结构变化

扩展现有公式语法树与 `formula-shift`，区分三种操作：复制时平移相对引用；移动内容时更新指向被移动内容的引用；插入/删除行列时变换相交/跨越的区域。绝对引用限制复制平移，不代表结构插入时永远不移动。删除失去目标的引用产生正确的引用错误，而不是指向相邻数据。

同一次变换同步处理名称、合并、结构化表、筛选/排序范围、条件格式、验证、批注/链接、打印区域/重复标题、绘图锚点与透视数据源。只在这些功能接入时增加对应处理。遇到无法解释且可能受影响的引用，拒绝该结构操作并返回原因；不能靠正则替换公式字符串或清除未知扩展完成保存。

共享公式命中后沿已有规则有界展开或重新分组。复制表时重映射局部名称、关系与图形身份，工作簿级名称按明确的冲突规则处理；重命名修改引用符号，不改字符串常量。名字和 sheet 名使用核心解析规则，覆盖引号、空格和 Unicode 名称。

### 3.3 样式、合并与冻结

样式修改为目标区域创建或复用等价格式记录，保持其他单元格的共享样式。清除内容、清除格式和全部清除是不同操作。数字格式解析属于核心；显示、导出和输入栏使用同一值/公式语义，延续 1900/1904 日期规则，不通过 JS 时区推断日期。

合并前明确非锚点内容的处理：存在将被丢弃的数据时由 UI 明示，核心只有收到明确策略才执行。拆分恢复网格，不虚构此前被丢弃的文字；撤销则恢复完整原值。自动行高/列宽由核心字体度量计算，保留换行、合并和最大尺寸边界。

冻结属于可保存的 sheet view 设置。核心生成冻结区与滚动区的裁剪/变换及命中映射，Renderer 复用 R0 绘制多个有界区域。选区仍是一份核心范围，不能为四个窗格分别创建工作表状态。

## 4. 计算、输入与剪贴板

### 4.1 常用函数和名称

先保留现有六函数，再按真实操作增量加入以下首批集合。函数共享错误传播、参数转换和引用迭代规则，不各自实现一套值系统。

| 用途 | 本阶段首批函数 |
| --- | --- |
| 逻辑与错误 | AND、OR、NOT、IFERROR、IFNA、ISBLANK、ISNUMBER、ISTEXT |
| 聚合与条件 | COUNTA、COUNTBLANK、SUMIF/SUMIFS、COUNTIF/COUNTIFS、AVERAGEIF/AVERAGEIFS、SUBTOTAL |
| 数值 | ABS、ROUND、ROUNDUP、ROUNDDOWN、INT、MOD |
| 文本 | LEN、LEFT、RIGHT、MID、TRIM、UPPER、LOWER、CONCAT/CONCATENATE、TEXTJOIN、FIND、SEARCH、SUBSTITUTE |
| 日期 | DATE、YEAR、MONTH、DAY、TIME、HOUR、MINUTE、SECOND、DAYS |
| 查找引用 | INDEX、MATCH、VLOOKUP、HLOOKUP、XLOOKUP、ROW、COLUMN、ROWS、COLUMNS |

优先建立类型和值/错误的独立结果，再加入具体函数。查找必须区分精确、近似、未命中与错误；SUBTOTAL 区分筛选隐藏与手动隐藏。文本函数的字符计数规则按选定参考实现确定，不能直接套编辑光标的字素规则。

名称先覆盖工作簿/工作表作用域的范围、常量与已支持表达式，解析作用域和循环。整行/整列引用用有界区间迭代和实际单元格查询，不能展开整个表。结构化引用随第 3 批表操作接入。外部工作簿、INDIRECT/OFFSET 等动态依赖、数组/溢出、易变和迭代计算在 P14 扩展，保留原公式与诊断。

### 4.2 未知公式的安全编辑范围

把“无法计算”和“无法确定引用影响”分开：

| 核心已知信息 | 可执行行为 |
| --- | --- |
| 公式与依赖均受支持 | 计算并编辑受影响区域，保存实际结果 |
| 函数未支持，但引用能完整解析 | 保留公式和导入缓存；可编辑确定无依赖联系的区域。影响该公式或依赖它的计算链时拒绝，直到对应求值能力完成 |
| 依赖范围无法确定 | 保守保护可能受影响的范围；不能证明隔离时继续整本只读，不猜测安全区域 |

格式或视图操作也要按实际语义判断是否影响公式；不能一概认为未知函数只读取数值。不得把旧缓存作为“本次已计算结果”返回。查询继续区分源码、导入缓存、已计算值与未计算原因，打印/导出沿该状态决定能否完整输出。

已支持公式采用现有依赖图增量重算。结构变化一次更新引用与依赖，再计算受影响部分；预算失败不提交半个工作簿。不先建设并行计算集群、通用插件函数注册或持久化计算缓存。

### 4.3 原生草稿、公式栏与片段

公式栏和网格内编辑共享 `spreadsheet-input` 的一个草稿、目标和 revision。两处控件显示同一草稿，只有活动入口持有原生输入；组合中不移动该输入节点。切格/切表、保存和打印沿现有提交屏障；错误保留草稿，不能提交到稍后选中的单元格。

核心片段包含矩形形状、值/公式、格式和合并信息，明确复制与剪切移动。粘贴模式包括全部、值、公式、格式和转置；核心执行相对引用变换及目标冲突检查。浏览器提供剪贴板载荷，不能先在 UI 改数据再同步核心。

保留现有 TSV 默认不执行 `=` 文本的行为；内部公式片段和用户明确输入公式是不同来源。填充柄只传源范围、目标范围与模式，核心推导序列和公式。日期序列使用工作簿日期规则，跨隐藏行/合并区域按明确规则执行或拒绝。

## 5. 数据、分析与绘图

### 数据规则与结构化表

排序先生成行/列置换，再一次更新所选区域的值、公式和相关属性；稳定处理相同键。标题是否参与、空值/错误排序和筛选隐藏行行为按参考规则明确。筛选保留用户手动隐藏状态，清除筛选不能把手动隐藏行全部展开。

条件格式保存规则、优先级、范围及差异样式，核心计算最终可见格式；不能把效果写成永久单元格格式。数据验证在手工输入与范围粘贴中共用检查，warning/stop 等行为显式返回；授权继续仍经核心验证。分列、去重和高级筛选先展示有界预览，提交时复核 revision 与覆盖范围。

结构化表拥有稳定名称、列身份、区域、表样式和总计行。扩表/插列同时更新计算列、结构化引用与相关关系。保护设置、行列大纲、批注线程/便笺和超链接各写回所属 XML/部件，显示和 API 共同遵守操作权限。

### 透视表、切片器与时间线

核心读取原始类型值，建立字段值集合与有界聚合，不使用格式化显示文字作为分组键。保存缓存定义/记录、透视定义、关系与输出区域；刷新时重新读取源数据并更新派生单元格。不能把一份普通值矩阵标成可刷新透视表。

字段拖放只修改分析定义；一次确认生成一次事务。源数据变更将透视标记为待刷新，用户刷新后更新结果；导出说明是否存在未刷新结果。输出扩大覆盖普通单元格时，默认拒绝并要求选择空白区域，不能覆盖用户数据。

切片器/时间线连接稳定的缓存和字段身份，筛选操作更新相关透视定义与结果，保存连接部件。首批仅连接同一受支持缓存；外部连接和复杂导入变体留给 P14。相同技术路线逐步加入其他聚合，不提前实现完整 OLAP 平台。

### 图表与工作表对象

图表复用 P10 已用到的系列、轴和绘制能力，XLSX 自己维护单元格数据源、范围变化和缓存。迷你图绑定单元格区域并随行列操作更新。绘图对象使用所属 sheet 的锚点：固定位置、单元格锚定和随区域变化分别保存；核心将行高/列宽换成对象几何。

图片、图形和文本框共用资源/文字布局与 R0 图元，XLSX 保留自己的锚点、选择及层次。符号作为文本，公式对象和图标按实际已有共用能力接入；不引入另一个 React/DOM 绘图模型。

## 6. SDK、UI 与输出

新增命令沿已有 XLSX 类型联合与 `XlsxClient` 增量扩展。拟定操作族如下，具体签名随该批一起实现并写入格式合同，不先增加空协议分支。

| 操作族 | 必须携带或返回的内容 |
| --- | --- |
| 创建/表结构 | budget、稳定表身份、插入位置/名称；返回新表与有效选区 |
| 行列/范围结构 | revision、sheet、范围、操作及明确的内容处理策略；返回变化后选区和相关限制 |
| 格式/名称/数据规则 | 类型明确的属性或规则；查询混合值、作用域与只读原因 |
| 复制/填充/排序/分析 | revision、源/目标范围、模式或分析定义；候选整体成功后返回查询状态 |
| 输出 | 输出格式、目标表/区域、布局选项与预算；结果绑定产生它的 revision |

Web 队列处理草稿与命令顺序。UI 按格式拆出工作表菜单、公式栏、格式、数据与分析面板，复用 P9 控件、Portal、稳定快照和保存回调。默认 UI 与自定义 UI 调用相同宿主方法，React 不直接调用 raw client。大范围的选区状态只返回摘要和所需记录。

CSV/TSV 解析在核心，使用明确分隔符、编码支持范围和有界行列。缺省按文字导入；数字/日期转换由用户选择，公式执行需要明确选择，不能通过 CSV 注入公式。CSV 导出明确只有所选表/区域的文本和值；格式、图形和多表损失需要提示。以公式前缀开头的文字按明确的安全导出策略处理，并说明其对重新导入的影响。

打印设置保存到工作簿，核心计算页分割、重复标题、页眉页脚和适合页数缩放，冻结窗格不改变打印。多表输出保留顺序与各表页面设置，包含本阶段已实现的图形；不使用浏览器测量来补表格分页。CSV/PDF 输出不确认 XLSX 已保存。
