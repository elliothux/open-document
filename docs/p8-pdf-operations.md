# P8 PDF 页面操作、批注与表单保存

状态：`planned`，2026-10-14。依赖 [P7 PDF 输入](p7-pdf-input.md) 的有界读取、源对象图、页面坐标和文字查询；P7/P8 均尚未实现。阶段顺序归[路线图](references/roadmap.md)，P6 的完成不代表已有任意 PDF 改写能力。

## 用户结果与范围

用户可以重排、旋转和删除页面，添加便笺与文字高亮，填写已有普通文本框和复选框，并撤销、保存和重开。使用同一个 PDF 会话，保留未修改页面、资源和未知对象；文件始终留在本地。

| 操作 | 首版范围 |
| --- | --- |
| 页面整理 | 同文档重排、90° 倍数旋转、删除；至少保留一页，稳定页身份不随页码变化 |
| 批注 | 添加/修改/删除符合支持条件的 Text 便笺与 Highlight；纯文本便笺，单页核心文字范围生成高亮，可查看批注列表 |
| AcroForm | 填写已有普通单行/多行文本字段，切换已有复选框；同步同一字段的多个 widget，遵守只读及 MaxLen |
| 恢复 | 有界撤销/重做、revision 冲突拒绝、候选取消、失败后显式恢复 |
| 保存 | 原对象图上的局部修改，生成可独立打开的 PDF；无编辑和全部撤销时返回原文件字节 |

不增加/复制页面，不做跨文件合并、拆分/抽取、裁切界面、任意正文或图片编辑、表单设计、扁平化、涂黑脱敏、OCR、签名、加密或 PDF/A/PDF/UA 转换。宏观架构沿 P7/R0；本阶段不建设通用对象编辑器或批注插件平台。

文件可预览不等于可修改。核心分别给出页面操作、批注、表单和保存能力，并提供具体保护原因。已签名、认证签名、加密或需修复才能读取的文件不进入可写会话；不能破坏签名后仍报告成功。P7 对签名的只读显示不授予签名验证能力。

## 原对象图与保存路径

```text
P7 源对象图 + 稳定页/字段/批注身份
        → MoonBit 命令校验 → 受影响对象候选 → 原子提交与历史
        ├→ P7 页面解释与文字查询 → 同一 Renderer
        └→ pdflite 对象 writer → 新 PDF → 独立重开
```

当前 `modules/formats/src/pdf/write.mbt` 把 Office 的定位图元生成新 PDF。P8 保存使用 pdflite 的对象 writer，保留原内容流和文档结构；不能通过“预览后重新导出”重建输入 PDF。两种入口服务不同格式操作，共享对象、字体及绘制编码，不是新旧实现兼容路径。

会话继续持有原始字节。对源对象使用带对象号/代数的引用；新增对象使用不冲突的新号。解析与显示只读源对象，解码缓存不得改变原 stream。修改只替换目标字典字段、数组成员或新增外观，未知键、其他页面、内容流、字体、图片、元数据及附件保持语义和关联。未变 stream 的压缩 payload 保持字节，不承诺改写后整个文件或字典排版相同。

首版只实现完整文件写出，复用 `pdf_write_document` 的对象序列化；不实现增量保存、压缩优化、线性化或去重。writer 重建 xref/trailer，正确处理原对象流中的对象与引用，不沿用失效的 `/Prev`、xref stream 或线性化偏移。未知且无法安全保留的结构导致保存拒绝，不能丢弃后继续。

无内容修改时直接返回原字节。全部撤销由历史状态判断内容回到源版本，revision 仍单调增加。保存返回绑定当前 revision 的新字节，不改原输入、不清空历史、不暗中替换打开基线；超限或序列化失败不返回半份文件。

页面删除和批注删除表示移出相应文档结构。首版保留未知及未引用对象，不清理附件或历史敏感内容，因此保存不能作为安全删除或脱敏操作。UI 的删除说明使用这一边界，不提供“彻底擦除”选项。

## 页面操作与关联保护

重排命令接收当前完整页身份排列，拒绝缺页、重复页和旧 revision。只调整页树顺序及必要的 Parent/Count，不换页对象身份。重挂页树前，把原继承的 Resources、MediaBox、CropBox、Rotate 等有效值保留到正确节点；不能因父节点改变而换字体、页框或方向。

旋转只更新目标页的 `/Rotate`，按 90° 归一化；不重复旋转内容流、widget、Rect 或 QuadPoints。P7 的页面变换负责同步画面、命中、选择与批注位置。原无效角度或非有限几何明确拒绝。

删除先计算受影响引用。保留页的链接、书签或命名目标若指向被删页，首版拒绝并列出原因；不把目标改指邻页，也不静默删除书签。删除页自己的普通批注可随页移出；包含 widget 或未知跨页关联时先保护该页，不同时引入表单树清理。

常见直接页引用随稳定身份保留；依赖页码的已支持内部目标由核心重映射。无法解释的页号目标、PageLabels、结构树、文章线程或扩展页关联使重排/删除受保护。旋转、批注和字段填写按各自影响范围判断，不能因为一个页面不可删而禁用所有操作。

重排/删除成功后，页列表和搜索页序按核心快照更新。当前页被删除时选择原位置的下一页，否则选择上一页；清除已删除页的选区。undo 恢复原身份、源关联和选择，不靠 Web 自行拼页树。

## 便笺与文字高亮

便笺保存 `/Subtype /Text`、Rect、Contents、颜色和必要身份；高亮保存 `/Subtype /Highlight`、QuadPoints、包围 Rect、颜色及透明度。便笺文字在可访问列表中编辑；Canvas 显示图标。UI 可以提供固定默认颜色，首版不做样式面板。

高亮输入为 P7 的页内文字范围，MoonBit 从最终四边形生成源 PDF 坐标。旋转文字保持四边形，跨行保留多个 quad；不能把屏幕轴对齐矩形当作 QuadPoints。只有可信映射和几何的范围可创建高亮。

核心生成 normal appearance，使保存后其他阅读器可显示。高亮按 ONLYOFFICE 的[外观实现](https://github.com/ONLYOFFICE/core/blob/3250a848ee4ef20c2fb8c38dc86350ec579124b8/PdfFile/SrcWriter/Annotation.cpp#L994)使用透明度和 Multiply。在共享绘制属性、P7 内容解释及外观编码中增加这一明确混合模式，让预览与保存一致；其他混合模式继续诊断。便笺外观使用简单路径图标，不引入字体图标库。

仅修改普通、未锁定、无回复/动作等未支持关联的 Text/Highlight。未知类型、锁定批注、回复链、富文本或不能重建的外观保持只读。删除仅更新目标页 Annots 和已确认的对象关系；不能批量调用“移除全部批注”。共享 appearance 只给目标复制后替换，不能改变其他批注。

现有 Tagged PDF 若批注带结构引用，或新增批注需要更新结构树，首版保护该操作。保留源无障碍关系，不假装新批注已满足 PDF/UA。

## AcroForm 字段与外观

MoonBit 解析 Fields/Kids、父级继承、字段类型/标志、完全限定名称及 widget 关系。字段身份绑定对象，不以名称字符串合并不同对象。一个终端字段可以对应多个 widget，填写时更新同一值及所有受支持的外观；若其中一个 widget 无法安全同步，整次修改拒绝。

| 字段 | 写回规则 |
| --- | --- |
| 普通文本 `Tx` | 修改 `/V`，保留 `/DV`；按 DA、Q、Rect、MK 及边框生成每个 widget 的 `/AP /N`，在局部 Resources 中登记所需字体 |
| 复选框 `Btn` | 排除 radio/pushbutton；读取实际导出状态名，不能假定为 `Yes`；同步字段 `/V` 与各 widget `/AS`，优先保留已有 Off/on appearance |

文本输入复用已实现的字体塑形、BiDi 和文本框布局。PDF 正文仍按 P7 的定位规则显示；只有新生成的字段外观需要排版。字体不足时由调用方提供可嵌入字体，写入局部字体资源；遵守嵌入权限，不替换文档共享字体。支持常规边框、纯色背景和基础对齐；未知外观属性保护字段。

文字为纯文本，单行拒绝换行，多行保留显式换行。核心检查 MaxLen、UTF-16 合法性与字素边界；不截断 surrogate/组合字符。固定字号溢出时拒绝提交并说明原因；DA 字号为 0 时在核心有界缩小。不能在 Web 看见全部文字、保存后却只显示截断值。

新外观使用原页面坐标和 widget 局部矩阵，保持其他阅读器打开后的文字和值一致。不能只更新 `/V`，也不能依赖阅读器按 `/NeedAppearances` 临时修复。若原文件设置 NeedAppearances，先检查所有相关外观；无法处理全局状态时保护填写，不盲目清除此标志。

复选框缺少可用 Off/on 外观时，首版保护，不自动猜测符号。文本字段的 rich text、comb、password、file-select、格式/校验/计算动作、签名字段，以及列表、下拉、单选按钮和 XFA 均保持只读。带 XFA 的 AcroForm 不修改，以免两套值不一致；不执行脚本、不提交表单、不发起网络请求。

## 事务、输入与恢复

每条命令携带 revision 和稳定对象身份。核心先收集受影响对象，深拷贝其可变容器形成候选，校验引用、可写条件、几何、资源和预算后再统一替换。依赖的可变容器不能穿透候选修改已提交源。历史保存改变对象的前/后值与必要选择，不保存每次编辑的整个文件或整个文档副本。

沿现有格式的提交/历史模式实现 PDF 局部事务，不新增通用事务框架。undo/redo 继续递增 revision；失败不增 revision，不改变历史或原源。一次页面操作、批注提交或字段编辑各形成一项历史。

首版使用可访问的属性面板填写便笺和字段。DOM 只持有未提交输入草稿；点击应用时由核心校验、排版并原子提交。输入法组合期间禁止应用/保存，取消丢弃草稿；切页、换字段或输出先明确提交或取消，不能把未提交草稿混入“已保存”。不在画布上再造文本编辑器或 PDF 正文输入流程。

宿主沿现有有界意图队列排序，保存等待已接受命令结束并绑定 revision。关闭等待在途操作、释放会话资源；旧请求不能重绘已关闭视图。提交后呈现失败保留已提交内容，停止新编辑，允许刷新或显式撤销；不能因为画面失败而自动回退源。

沿用 P7 读取/解码与现有字体、图片、Canvas 预算。新增默认上限：每文档批注及 widget 各 4096，字段树深度 64，单字段/便笺 32767 UTF-16 单元，单高亮 4096 个 quad；undo+redo 共 100 项、8 MiB 对象补丁。单次事务候选同受 8 MiB 限制，超限先拒绝；共享未变 stream，不把图片数据重复放进历史。

保存输出上限沿用 64 MiB。在对象编码和输出累计时扣预算，检查最大对象号与 xref 长度，不能先分配完整大文件再检查最终长度。打开、编辑、历史、序列化使用同一预算语义；这不是总堆峰值承诺。

## 实施顺序与影响面

1. 在 P7 会话上实现局部事务和对象保存。先完成旋转/重排/删除、保护规则、撤销及独立重开。
2. 完成便笺与高亮。接入 P7 选择几何、核心外观和可访问批注列表。
3. 完成已有文本字段与复选框填写。接入字段树、局部外观、原生草稿输入和保存屏障。
4. 核对未修改内容与失败恢复。补实际 API、支持限制及嵌入示例，再归档交付结果。

`modules/formats/src/pdf` 增加页面命令、批注、字段、外观、事务及保存职责；复用现有对象 writer 和字体资源编码。通用文字框、几何和绘制缺口回到 `modules/layout/src`，不复制 Office 布局实现。模块按职责拆分，遵守单文件 800 行。

同步 `PdfSession` 与 Worker `PdfClient` 增加类型化 `reorderPdfPages`、`rotatePdfPages`、`deletePdfPages`、批注命令、`setPdfFieldValue`、undo/redo、`savePdf`。具体参数由上述合同约束，名称在实现时一次确定，不保留旧 API 垫片。P7 的 `PdfViewer` 复用到 `PdfEditor`；共享页面呈现/资源，编辑宿主增加按钮、列表和输入面板。

桥接分发、wasm/web exports、Worker 协议、构建入口和受影响调用方同步修改。私有用例更新既有 P7 功能链；公开文档更新[格式](references/formats.md)、[开发](references/development.md)及必要依赖说明。未知格式能力继续保留明确诊断，不扩展浏览器或发布范围。

## 足够检查与参考依据

三条功能链足够组织首版检查：页面整理 → undo/redo → 保存重开；选择文字 → 高亮/便笺 → 修改/删除 → 保存重开；文本/复选框填写 → 取消/提交 → 保存重开。每条都核对用户结果与非目标源内容；独立 qpdf/Poppler 检查结构、文字和少量选定页面，参考应用核对批注和字段外观。

输入优先固定 ONLYOFFICE，LibreOffice 补充字段与批注。页继承、共享资源、多 widget、非 `Yes` 状态名、旋转后的 QuadPoints、NeedAppearances 和受保护关联分别并入功能用例。旧 revision、外观失败、输出/历史超限和关闭/恢复补直接风险检查；源 stream 与未知字典用独立解析结果核对。不能只用同一 writer 保存再由同一 reader 重开判定保真。

只对新增的对象变更、外观和真实边界风险补小型单元回归。共享字体/绘制发生改变时重跑对应 Office 输出链，不默认全量 loop、完整 PDF 兼容矩阵或性能验收。当前方案只查文档，未执行这些产品检查。

机制优先参考 ONLYOFFICE 的[页面删除与历史](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/pdf/src/document.js#L3212)、[复选框实际导出值](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/pdf/src/forms/base/basecheckbox.js#L688)及[字段外观写出](https://github.com/ONLYOFFICE/core/blob/3250a848ee4ef20c2fb8c38dc86350ec579124b8/PdfFile/SrcWriter/Field.cpp#L514)。本项目把这些语义放入 MoonBit，不照搬其 JS 文档模型。

保存复用固定 pdflite 的[对象复制](https://github.com/moonbitlang/office.mbt/blob/2f08f3b8041d9098d258969fe3902b34585163cc/pdflite/pdf_document_core.mbt#L33)和[对象 writer](https://github.com/moonbitlang/office.mbt/blob/2f08f3b8041d9098d258969fe3902b34585163cc/pdflite/pdf_writer_classic.mbt)。关联保护另参考 LibreOffice 的[批注结构引用检查](https://github.com/LibreOffice/core/blob/1746b16a564f59fcaf8c5670bb292748408da54e/vcl/qa/cppunit/pdfexport/pdfexport.cxx#L160)。ONLYOFFICE `EditPdf` 示例测试含 `GTEST_SKIP()`，仅作行为阅读入口，不记为本项目或上游自动通过。引用不等于移植代码，沿原许可证记录来源。
