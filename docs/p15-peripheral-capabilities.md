# P15 次要与外围能力接入

状态：`planned`，2026-11-02。本阶段对应[路线图](references/roadmap.md)的功能优先级 P2（见 [G3 功能对照](g3-genoffice-sdk-gap.md) 的 D20、D22、F17、F18、C07–C09）。在 [R2 架构精简](r2-architecture-and-performance.md)、[C0](implemented/c0-real-file-compatibility.md)/[C1](c1-corpus-and-producer-compatibility.md) 核心兼容及 [P16.1 无浏览器核心闭环](p16-cross-host-runtime.md)完成后推进。所有外围能力均通过 MoonBit 核心的事务与校验接口工作，外部模型、OCR、证书与网络存储由宿主显式注入。

## 用户结果与范围

1. **原生文档比较（Diff）**：用户在 DOCX（及后续扩展的 XLSX）中对比两份文档版本，核心直接计算段落、表格与格式差异，生成结构化差异列表与可视化高亮，不依赖外部 DOM 比对。
2. **AI 结构化命令接入**：宿主可将 AI 模型或 Agent 接入编辑器，通过类型化查询读取文档语义摘要，并通过统一 `execute(command)` 提交可撤销、受保护规则约束的编辑事务。
3. **宿主辅助服务接口（OCR / 校对 / 引用）**：纯扫描 PDF 页面或图片可通过宿主提供的 OCR Provider 生成可搜索/可转换文本层；拼写校对与 Zotero 等外部引文库通过标准回调接入。
4. **PDF 数字签名状态与签署接口**：读取并展示 PDF 已有数字签名范围与篡改状态；支持宿主注入外部证书/签名器完成摘要计算与增量签署写回。
5. **协作原语准备**：定义基于核心操作日志的增量事务序列化、版本冲突检测与重连重放合同，不绑定特定后端传输服务。

## 架构边界与安全约束

1. **禁止绕过核心直接改模型**：AI、OCR、校对与协作同步均不得在 TS 层直接拼接 XML 或修改 Canvas；所有文档变更必须通过 MoonBit 核心事务提交，保留完整的 `revision`、撤销历史与资源预算检查。
2. **零隐式外发**：SDK 核心与默认 UI 不内置任何硬编码 API 端点、遥测或第三方云调用。未配置对应 Host Provider 时，编辑器隐藏或禁用对应外围入口，核心本地编辑功能 100% 正常可用。
3. **原子性与可恢复**：AI 批量操作或外部 Provider 返回非法坐标、越界文本或受保护区域修改时，核心原子拒绝整次事务，原文档会话与未保存修改不丢失。
