# XLSX 透视表、分析与打印

[格式合同目录](../formats.md)

### 透视表核心

单行字段、单普通值的原生大纲透视表可在默认面板刷新。核心保留原报表起点、样式、修订标识和已识别的扩展，并随结果一起写入缓存。紧凑布局保留报表原行标题。共享缓存、分组、筛选、切片器、时间线和未知扩展仍按现有保护处理。实现归 [`pivot-native.mbt`](../../../modules/formats/src/xlsx/pivot-native.mbt)。布局和行标题依据 [ONLYOFFICE 原生刷新](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/Workbook.js#L11249-L11278)。

`PivotStyleLight15` 可绘制单行字段、单值透视表。网格、格式查询和打印共用样式。标题、总计、条带及边线按原生标记和工作簿主题计算，直接单元格格式优先。样式绘制沿用报表定义，保存保留原始样式部件。分组布局的其他区域仍待实现。实现归 [`pivot-style.mbt`](../../../modules/formats/src/xlsx/pivot-style.mbt)。区域顺序依据 [ONLYOFFICE 透视表样式](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/Workbook.js#L11495-L11620)。

`PivotSettings.source` 可使用标题/数据矩形，或 `sourceSheet` 所属结构化表的名称及 `Table1[]`。表名匹配忽略大小写，原生 `worksheetSource@name` 保留实际名称，不改写成固定区域。表必须有一行标题及数据，总计行不参与聚合。表范围变化使缓存待刷新；刷新读取当前数据边界。改名和源列插删维护共享报表、切片器及独立时间线日期缓存；被使用列删除和覆盖报表的扩张仍拒绝。删除表时保留原区域绑定；删除源工作表时保留原缓存和显式恢复入口。普通定义名称、部分结构化引用和外部源继续保护。实现归 [`pivot-table-source.mbt`](../../../modules/formats/src/xlsx/pivot-table-source.mbt)，依据 [ONLYOFFICE 原生名称与表范围](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L14729-L14935)。沿用已有字段、记录及事务预算。

普通区域行列轴透视表已接通 MoonBit、Wasm、Worker、编辑宿主和默认面板。`Session::pivot_preview(revision, settings)` 返回字段、记录数、类型化分组结果及总计，查询不写源或历史。预览最多返回前 20 个行分组，groups 和 truncated 说明完整输出行数（含小计、不含总计）及截断状态；总计与实际创建仍处理全部筛选后记录，JSON 继续受 1 Mi UTF-16 上限约束。`PivotSettings` 为 `{ sourceSheet, source, rows, columns, filters, subtotals, numberGroups, dateGroups, values }`；sourceSheet 是稳定工作表部件身份，source 包含标题行。rows 和 columns 使用相对源区域、从 0 开始的列索引；两轴不能重复字段，columns 空数组表示只有行轴；每项 values 为 `{ field, aggregate, baseItem, baseField, showDataAs, name }`，name 是显示标题。标题按当前格式读取且不能为空，重复标题在缓存中分配唯一名称，不改源格；值标题不能与源字段名称重复。

filters 为 0–8 项 `{ field, report, values }`，三项均必需。field 使用源列索引，筛选字段不能重复。report 为 true 时放入报表区，不能同时属于行列轴；false 表示原位成员筛选，不增加报表行。行列字段保留轴位置；布局外的有效成员条件必须连接原生切片器或时间线。values 为 null 时选择全部成员，自动包含后续新增成员；类型化 Value 数组选择指定成员，空数组明确不选择任何成员，单字段内取并集，字段之间取交集。文字匹配合并大小写，数字、文字数字、布尔、错误与空白保持类型；每字段最多 4096 个成员。普通字段保留完整缓存记录与已选但暂时缺失的成员，刷新不静默改指其他成员。成员筛选选中全部当前缓存项时，按原生隐藏项规则清除该筛选，目录不再返回这项条件；报表字段仍保留其固定列表。预览 recordCount 是源记录数，filteredCount 是筛选后记录数，filterItems 是各字段的 `{ value, label }` 候选项，label 由核心按有效格式生成。零匹配允许，返回空分组及空白总计。

报表筛选格按字段顺序纵向排列，其后留一空行。目录 range、覆盖保护、更新原点和删除范围包含筛选格；原生 location.ref 仅含表头及聚合结果。选择保存为原生 pageFields、axisPage、item 与隐藏成员标记。默认面板提供全部/类型化多选，改动后预览再应用。横向、换行或未知原生分页布局保持保护。布局和成员筛选依据 [ONLYOFFICE 报表位置](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L4323-L4342)、[成员筛选](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L5103-L5139)与[报表值](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L5237-L5267)。

行列成员筛选不增加报表行，保存 `axisRow/axisCol` 与 `pivotField/items/item@h`，刷新时按成员身份重建索引。目录先返回报表字段，再按源列顺序返回有效行列条件；报表字段内部顺序保持。数值和日期分组使用原生分组项作为候选，按原始记录聚合；多级日期源字段筛选最细层。分组项消失时原子拒绝刷新，保留待刷新的源，先修改条件再继续。派生日期层级的独立筛选仍保护。默认面板分别添加报表和行列筛选，共用成员选择、预览、应用和精确历史。成员集合及原生隐藏项生成使用有界索引，避免按每个缓存项重复扫描选择列表。依据 [ONLYOFFICE 隐藏项应用](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L17359-L17376)及[清除筛选判断](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L7495-L7517)，实现归 [`pivot-filter.mbt`](../../../modules/formats/src/xlsx/pivot-filter.mbt)。

原生切片器已有目录。`XlsxClient.execute({ operation: "slicersXlsx", revision, sheet })` 与 `SpreadsheetEditor.objects.slicers()` 返回控件、缓存、字段、关联透视表及类型化成员；成员包含 `selected` 和 `hasData`。按工作簿原生缓存 ID、工作表 ID 和透视表名称解析连接，查询不刷新结果，不改变源或历史。仅支持普通表格缓存；未知、歧义、外部或不一致连接返回空目录和 `reason`，预算越界则报错。未引用的其他缓存保持原样。每表最多 64 个控件，每缓存 4096 个成员，每次目录共 16384 个成员，JSON 限 1 MiB；标签使用缓存值，不推断源单元格格式。实现归 [`slicer.mbt`](../../../modules/formats/src/xlsx/slicer.mbt)，原生结构参考 ONLYOFFICE core 的 Slicer 实现及 `xl14.xsd`。

`editSheet({ action: "filterSlicer", name, indices })` 按当前目录的原生成员索引筛选。至少选择一项，重复、越界、旧 revision、受保护或隐藏目标原子拒绝。普通透视表的源字段可位于行、列、报表区，也可不占布局位置。布局外字段写入原生隐藏项，不生成 `axisPage/pageFields` 或额外报表行。读取有效隐藏条件时校验切片连接；没有连接则保护原源，不能将无效条件写成普通可刷新透视表。该语义依据 [ONLYOFFICE 布局外切片条件](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L5156-L5172)。全选清除成员条件，保留报表位置。一次更新同缓存最多 16 张关联透视表，所有变化的输出合计限 65536 格；只读取原生缓存记录和分组，保留缓存定义、记录、索引及待刷新源值。两个关联表中任一输出扩大遇到内容，整次操作保持源、历史、选择和重做。结果、原生隐藏项和受影响切片缓存合为一条精确历史；同缓存的多个控件共享状态。其他字段条件取交集，各成员的 `hasData` 排除本字段条件后计算；`crossFilter="none"` 不标记无数据，其他模式同步 `nd`，按原生类型和值排序，必要时将有数据项前置。多个关联表保留各自条件，切片缓存采用本次最后处理的关联表状态，与 [ONLYOFFICE 逐表应用及同步](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/Slicer.js#L1448-L1499)一致。

默认面板已有读取、多选、全选、应用及无数据提示，旧目录禁用应用。透视字段面板显式选择报表或成员筛选位置，不再按字段是否位于行列轴推断。已识别的切片器关系元数据不参与单元格尺寸，允许继续输入和结果区 PDF；未知扩展仍阻止导出，绘图内容继续独立检查。关联源列映射沿下述 `updatePivot`；删除被使用源列与分组修改仍保护缓存连接。实现归 [`slicer-edit.mbt`](../../../modules/formats/src/xlsx/slicer-edit.mbt)、[`slicer-state.mbt`](../../../modules/formats/src/xlsx/slicer-state.mbt)及 [`pivot-cached.mbt`](../../../modules/formats/src/xlsx/pivot-cached.mbt)。滚动条拖动、删除被使用源列及关联分组修改继续实施；时间线归[原生时间线目录](#原生时间线目录)。

`editSheet({ action: "refreshPivot", part })` 与默认“刷新透视表”会一起刷新同一原生缓存的全部透视表和相关切片缓存。最多处理 16 张表，变化输出合计限 65536 格。源范围、标题和分组必须一致；每张表保留自己的行列、报表/成员条件及值显示设置。核心从当前源值生成一次缓存，按类型化成员身份重映射全部结果和切片索引，合并保留各表已选但暂时缺失的普通成员及比较基项。全选自动包含新成员，分组中已选成员消失仍原子拒绝。各切片缓存同步选择、排序和无数据状态，沿其最后一个关联表的条件计算。原生条目索引未变化时只修改需要变化的标记，避免无变化刷新产生历史。成员缩减使显示偏移越界时，绘图从首项显示，保留原生源偏移。

缓存定义、记录、结果、隐藏项和切片状态合为一项精确历史，并保留单元格选择。任何关联表保护、扩张覆盖、标题变化、未知元数据或预算失败都保留整组源、历史与重做。最后一个可见控件删除后保留的缓存连接也参与刷新。原生透视目录可读取共享缓存设置，Wasm、Worker 与默认面板沿用既有刷新入口。实现归 [`pivot-shared-refresh.mbt`](../../../modules/formats/src/xlsx/pivot-shared-refresh.mbt)和 [`slicer-refresh.mbt`](../../../modules/formats/src/xlsx/slicer-refresh.mbt)。连接与成员同步依据 [ONLYOFFICE 透视缓存更新](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L6761-L6792)和 [CT_tabularSlicerCache.syncWithCache](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/Slicer.js#L2797-L2820)，未复制上游源码。

`SpreadsheetEditor.objects.insertSlicer(settings)` 与 `XlsxClient.execute({ operation: "insertXlsxSlicer", revision, sheet, settings, profile })` 创建原生切片器。`XlsxSlicerSettings` 必须包含 `pivot/field/name/caption/width/height` 六项；pivot 为原生透视表部件，field 为原始源列的零基索引，最多 63。名称在工作簿内唯一，标题为非空文字且最多 255 个 UTF-16 单元；宽高使用磅，范围为 0.1–14400。控件定位于当前选区左上角，使用随单元格移动的原生锚点、Light1 样式及 19 磅成员行高。默认面板读取当前工作表的透视表，源列输入使用一基编号，初始尺寸为 144×132 磅。

创建只读取已保存的透视缓存，保留待刷新源、缓存定义、记录和透视结果。相同透视表及源字段复用既有切片缓存；新视图使用独立部件。没有匹配缓存时，核心创建缓存、原生连接、工作簿与工作表扩展、绘图、关系和内容类型，并按当前筛选同步成员状态。新缓存名称避开原生缓存、定义名称和表格名称；已有 UID 的同类部件继续使用唯一 UID，混合 UID 声明保护创建。控件绘制和字体校验通过后，全部资源合为一项精确历史，保留单元格选择。实现归 [`slicer-create.mbt`](../../../modules/formats/src/xlsx/slicer-create.mbt)、[`slicer-create-cache.mbt`](../../../modules/formats/src/xlsx/slicer-create-cache.mbt)和 [`slicer-create-source.mbt`](../../../modules/formats/src/xlsx/slicer-create-source.mbt)。缓存复用依据 [ONLYOFFICE CT_slicer.init](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/Slicer.js#L408-L445)。

`editSheet({ action: "deleteSlicer", name })` 与默认成员面板的“删除切片器”一起移除目标原生控件及其整段绘图锚点，包含兼容后备。共用视图部件中的其他控件保留原字节；删除最后一个条目时，移除该视图部件、工作表入口、关系和内容类型声明。其他绘图、空绘图容器和共享切片缓存保持。删除控件保留当前筛选、透视结果、原生缓存记录和待刷新源；最后一个可见控件移除后仍保留缓存连接，以保存布局外字段的筛选条件。以后为同一字段创建控件可复用该状态。全部变化合为一项精确历史，保留单元格选择，支持保存重开。旧 revision、失联名称、保护、绘图选择锁、共享视图部件或未知所属关系原子拒绝。实现归 [`slicer-delete.mbt`](../../../modules/formats/src/xlsx/slicer-delete.mbt)；控件删除与筛选分离沿 [ONLYOFFICE Worksheet.deleteSlicer](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/Workbook.js#L12670-L12698)。删除被使用源列及关联分组修改继续实施；协调删除与缓存回收沿透视表删除事务。

原生切片器绘图已接通 Canvas 与静态 PDF。核心按名称连接工作表控件，读取固定、随单元格移动及随单元格缩放三类锚点，并解析 `a14` 的 `mc:AlternateContent/Choice`，保留原 fallback。Light1–6、Dark1–6 与 Other1–2 共 14 种内置样式已显示普通选中/未选中、有数据/无数据状态；Other2 的普通状态和全部内置悬停状态使用原生垂直渐变。标题、列数、行高和首个显示项沿原生设置，文字使用工作簿默认字体与同一布局探针。锚点、裁剪、冻结/滚动视口和打印沿既有绘图通道。实现归 [`slicer-drawing-read.mbt`](../../../modules/formats/src/xlsx/slicer-drawing-read.mbt)、[`slicer-palette.mbt`](../../../modules/formats/src/xlsx/slicer-palette.mbt)和 [`slicer-paint.mbt`](../../../modules/formats/src/xlsx/slicer-paint.mbt)；几何与样式事实参考 [ONLYOFFICE SlicerView](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/common/Drawings/Format/SlicerView.js)和 [ReadDefSlicerStyles](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/Serialize.js)，未复制上游源码。画布成员、标题的多选/清除按钮、滚轮及键盘滚动已接通；滚动条滑块已有原生行位置和默认垂直控件；成员拖选沿下述核心候选入口处理；原生成员悬停沿下述临时视口参数处理。自定义/未知样式、未解析控件或未知兼容分支保护打印；框属性编辑及画布手势沿下述协调入口；普通绘图复制与层次入口继续保护切片器。行列尺寸变化可同步修改坐标一致、无旋转及变换注释的平面形状 fallback，保留其余源字节；其他后备结构保护修改。新建控件使用该兼容结构，允许继续输入引起的自动行高变化。实现归 [`slicer-reflow.mbt`](../../../modules/formats/src/xlsx/slicer-reflow.mbt)。

`viewport({ ..., slicerHover: { object, index } })` 临时指定原生绘图身份和成员索引（0–4095）；省略参数恢复普通配色。核心按选中及有数据状态选择内置 DXF，悬停参与视口缓存。参数不写源、选择、历史或打印结果；未知或不可见成员不产生悬停绘制。默认宿主从既有可见按钮传递指针事件，在原有有界队列中只更新画布，不发布忙碌状态或提交输入；移出、滚动、取消及换表清除悬停，拖选期间沿原候选绘制。键盘焦点保留既有轮廓，触摸不生成悬停。实现复用 [`slicer-palette.mbt`](../../../modules/formats/src/xlsx/slicer-palette.mbt)、[`slicer-paint.mbt`](../../../modules/formats/src/xlsx/slicer-paint.mbt)及 [`spreadsheet-slicers.ts`](../../../packages/xlsx/src/web/spreadsheet-slicers.ts)；配色及渐变角度来自固定 [ONLYOFFICE ReadDefSlicerStyles](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/Serialize.js#L14681)，未复制上游执行代码。

`SpreadsheetEditor.objects.setSlicerFrame(id, frame)` 修改当前表的原生切片器框。`XlsxSession` 与 Worker `XlsxClient` 使用 `execute({ operation: "frameXlsxSlicer", revision, sheet, id, frame, profile })`；MoonBit 入口为 `Session::set_slicer_frame`。frame 仅含 `anchor/x/y/width/height`，anchor 为 `fixed/move/size`，对应固定、随单元格移动和随单元格缩放。坐标与尺寸使用磅，位置非负且受工作表边界限制，宽高为 0.1–14400。当前框从已测量视口的 `object.slicer.frame` 读取，不向无字体的成员目录加入绘图布局。导入的折叠框可读取零尺寸；提交仍要求有效正尺寸。默认成员面板提供锚定、位置、宽高及应用按钮，沿原生草稿屏障和串行队列提交。

`XlsxViewport.objects` 的 `slicer` 项携带核心计算的 `slicer` 视图：`name/caption/frame/move/start/maximum/page`、可见成员 `buttons`，以及 `clear/multi/previous/next/scroll` 的裁剪区域。start 与 maximum 是零基滚动行位置和末行，page 是完整可见行数；多列成员的索引仍只在按钮中返回。scroll 使用避开两端箭头的完整轨道及各窗格裁剪，不从 DOM 推断文档几何。每个按钮返回原生成员 `index`、标签、选择/数据状态和 `regions`；视口滚动、冻结与 RTL 沿同一坐标换算。`editSheet({ action: "selectSlicer", layout, id, index, additive })` 使用当前视口 ID 和绘图 ID；index 为原生成员索引，null 表示可见标题的清除按钮，并要求 additive 为 false。普通点击只选当前项，Ctrl/Cmd 或标题多选模式切换单项；取消最后一项保持原状态，沿至少一项的既有合同。隐藏成员、其他工作表、旧布局及受保护源保持原子拒绝。

`editSheet({ action: "scrollSlicer", layout, id, position })` 设置绝对零基行位置。position 为 0–4095 的整数，核心裁剪到末行，再按原生列数定位首个成员；每会话最多保留 4096 个控件偏移。滚动只改核心视图状态，保留文档字节、revision、选择、历史和重做；打印使用当前可见成员，保存重开恢复原生 `startItem`。默认画布使用核心区域放置具名按钮和 `aria-pressed`，支持 Tab、Enter/Space、多选、清除、滚动箭头和滚轮；方向上下、PageUp/PageDown 与 Home/End 在控件内滚动；垂直滑块沿同一入口实时定位，保留当前滑块焦点并提供行位置说明。Escape 返回原单元格输入。被替换或禁用的焦点回到可见成员，支持默认 UI 的 Shadow DOM。实现归 [`slicer-pointer.mbt`](../../../modules/formats/src/xlsx/slicer-pointer.mbt)、[`xlsx-slicer-view.ts`](../../../packages/xlsx/src/core/xlsx-slicer-view.ts)和 [`spreadsheet-slicers.ts`](../../../packages/xlsx/src/web/spreadsheet-slicers.ts)。

`XlsxSession/XlsxClient.execute({ operation: "slicerGestureXlsx", revision, layout, id, gesture, profile })` 预览或提交成员拖选，核心入口为 `Session::slicer_gesture`。`XlsxSlicerGesture` 包含原生首项身份 first、绝对滚动行 position、视口磅坐标 x/y、additive 和 commit。首项须在原始布局可见，末项按核心裁剪区域定位，区间采用实际显示顺序，不把成员身份当成排序位置。普通拖动选中整个区间；Ctrl/Cmd 或标题多选模式反转区间内原有状态。反选后没有成员时保持原筛选。

预览复用已有缓存筛选与布局，只生成独立候选，保留源字节、revision、单元格选择、历史、重做和原视图。松开后沿既有协调筛选提交一项历史，并保留候选滚动行；不刷新待处理源数据。字体在提交前预检。切片器与时间线手势共用 `XlsxAnalysisPreview`，仅 query 或 drawing 一项非空，传输验证归绘图模块。

默认成员按钮复用既有指针捕获与队列。按住时在上下边缘滚动候选，Ctrl/Cmd 可实时切换区间反选；Escape、失去捕获、窗口失焦或视口变化取消。预览期间不把派生文字交给 TypeScript 保存。松开或取消后刷新控件并聚焦可见成员，键盘单项选择沿原入口。范围、缓存、资源及历史上限沿已有切片器合同，未知源、过期布局和缺字体保持拒绝。实现归 [`slicer-gesture.mbt`](../../../modules/formats/src/xlsx/slicer-gesture.mbt)与 [`spreadsheet-slicer-pointer.ts`](../../../packages/xlsx/src/web/spreadsheet-slicer-pointer.ts)。范围与反选依据 [ONLYOFFICE 成员拖选](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/common/Drawings/Format/SlicerView.js#L2220-L2268)，未复制上游执行代码。

预览的 columnMembers 按列组合返回 `{ members, formats, subtotal }`，columnTotals 为每个列组合的值字段总计。每项 rows.values 按“列组合、值字段”展平，rows.total 是该行全部记录的总计；根 total 是筛选后源记录的总计。没有列轴时 columnMembers 为空、columnTotals 只含根总计，rows.values 仍按值字段排列。缺少记录的交叉格为空。行列边际直接累积源记录，平均值和样本统计不会对显示聚合值二次聚合。预览只截断行，全部有界列组仍受结果格数及 JSON 文字预算约束。

`showDataAs` 为必需字段，使用导出的 `xlsxPivotValueModes`：`normal`、`percentOfTotal`、`percentOfRow`、`percentOfCol`、`index`、`percentOfParentRow`、`percentOfParentCol`、`runTotal`、`percentOfRunningTotal`、`rankAscending`、`rankDescending`、`difference`、`percent`、`percentDiff` 或 `percentOfParent`。普通值使用上述聚合；总计/行/列百分比分别除以筛选后的全体、当前行或当前列的原始记录聚合。指数按“当前值 ÷ 列聚合”再除以“行聚合 ÷ 全体聚合”计算，避免先乘两个大数。小计与总计使用各自的原始记录，均值不会对可见均值求和。预览中的数值是应用显示方式后的比例或指数。普通模式的空交叉格保持空白，总计百分比的缺失交叉项为 0；其他模式将缺失分子按 0 参与除法，空白分母保持空白。错误值沿分子、分母传播，零分母返回 `#DIV/0!`，非有限结果返回 `#NUM!`。

父行/父列百分比去掉相应轴的最后一层成员，保留另一轴的当前成员，使用该父级筛选后原始记录的同种聚合做分母。关闭小计显示仍计算父级；数字分组及多级日期的派生轴遵循同一层级。值字段不算成员层级，多值可分别使用不同模式。最外层使用该轴的总计，祖先小计继续相对其直接父级；总计相对自身，非零时为 100%。均值子项的百分比可能不合计为 100%，因为父级均值按全部原始记录计算。

`baseField` 为必需的 `number | null`，使用源区域从 0 开始的列索引。累计值、累计百分比、两种排名、基项比较及指定父项百分比要求它属于当前行轴或列轴，其他模式必须为 null；Wasm/Web 导出 `xlsxPivotBaseModes` 供面板查询。累计按该轴已有成员顺序推进，固定其他成员和小计层级；均值等模式累计已聚合的单项值。缺少的交叉项按 0 累加，错误传播到同组后续项，非有限累计返回 `#NUM!`。基准字段以上的小计及该轴的总计留空；另一轴的总计独立累计。筛选先于累计，修改基准、隐藏小计、刷新和重开沿同一事务。数字分组使用分组顺序，多级日期以原源字段对应的最细级别为基准，并按上层日期分组重新累计。默认面板显示从 1 开始的基准列，预览后确认；无效字段禁用预览。原生保存 `dataField@showDataAs="runTotal"` 和 `@baseField`，不改变缓存原始记录。累计只遍历已有的有界结果矩阵，不展开空白工作表。依据 [ONLYOFFICE 基准字段与总计规则](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L11502-L11528)、[累计计算](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L11971-L11989)及[原生基准字段](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L18199-L18214)。实现归 [`pivot-axis-values.mbt`](../../../modules/formats/src/xlsx/pivot-axis-values.mbt)，未复制上游源码。

`percentOfRunningTotal` 在相同基准上累计。当前成员层级恰好到基准字段时，分母使用父级原始记录的同种聚合；存在更深层成员时，分母使用固定其他成员的整组累计。均值等非加法聚合的最后一项可能超过 100%，沿 ONLYOFFICE 行为保留。分母为零或空白时显示空白；错误分母传播到整组。累计百分比沿既有父级聚合预算，在隐藏小计时也保留分母。`rankAscending/rankDescending` 对同组非空数值排序，错误和缺失交叉格不参与且结果留空。相同数值使用相同名次，后续名次连续，例如 1、1、2；正负零视为相同值。基准以上的小计及该轴总计仍留空。三种模式使用同一 x14 扩展并在外层 dataField 写 baseField；百分比声明格式 10，排名声明格式 0。依据 [ONLYOFFICE 累计百分比](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L11991-L12038)和[升降序排名](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L12040-L12118)，未复制上游源码。

`baseItem` 为必需的 `XlsxPivotBaseItem | null`。三种基项比较模式必须提供 `previous`、`next` 或类型化 `CellValue`，其他模式必须为 null；`xlsxPivotCompareModes` 返回这三种模式。`difference` 计算当前聚合减基项聚合，`percent` 计算当前聚合除以基项聚合，`percentDiff` 计算差值除以基项聚合。比较固定其余成员及小计层级，基准以上的小计和该轴总计留空。前后项按实际成员顺序比较；两端没有邻项时，差值和百分比差异留空，基项百分比对有效数值按自身比例计算。明确选择的基项自身也按此规则处理。差值把缺失交叉项视为 0；两种百分比的缺失当前交叉项返回 `#NULL!`，缺失基项交叉项留空，零基项返回 `#DIV/0!`。基项成员在当前分组内不存在时返回 `#N/A`。错误规则沿 [ONLYOFFICE 基项比较](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L11769-L11970)，不把源错误改写成数值。

指定成员按类型和值保存；文字沿缓存的大小写合并规则，数字与文字数字不混用。普通轴会在缓存中保留已选但消失的成员，刷新后重新映射原生 baseItem 索引，缺少该成员的交叉结果为 `#N/A`。重建分组后已选标签不再存在时，刷新拒绝并保留原结果，用户先选择其他基项。预览新增必需的 baseItems，与 values 等长；每项为当前比较基准的 `{ value, label }` 候选，非比较模式返回空数组。每组最多 4096 项，JSON 仍受 1 Mi UTF-16 上限约束；默认面板先预览加载候选，再选择并重新预览确认。类型化成员及保留成员共用原共享项文字预算。`dataField@baseItem` 保存缓存索引，前一项/后一项分别保存 1048828/1048829；上述三种比较模式使用标准 `showDataAs`。实现归 [`pivot-base-item.mbt`](../../../modules/formats/src/xlsx/pivot-base-item.mbt)、[`pivot-compare.mbt`](../../../modules/formats/src/xlsx/pivot-compare.mbt)和 [`xlsx-pivot-base-item.tsx`](../../../packages/xlsx/src/react/xlsx-pivot-base-item.tsx)。

`percentOfParent` 以 baseField 所在层级作为指定父级，分母为该前缀与另一轴当前成员的原始记录聚合；隐藏小计也计算分母。当前层级不包含基准字段时留空，当前值已在所选层级时相对自身。父级聚合继续受既有工作及保留值预算约束，原生设置使用 x14 扩展并携带 baseField，不使用 baseItem。依据 [ONLYOFFICE 指定父级百分比](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L11736-L11764)，复用现有 [`pivot-parent-values.mbt`](../../../modules/formats/src/xlsx/pivot-parent-values.mbt)，未复制上游源码。

默认值字段面板提供“值显示方式”，读取、修改、预览和应用共用同一设置。百分比结果格使用 `0.00%`，局部样式助手按现有规则分配格式身份；原生 `dataField` 声明内置格式 10。指数、累计值、排名与差值使用 General；切回普通值将原非普通显示格设为 General，保留字体、填充、边框等其他样式。普通模式刷新继续保留已有结果格式。原生基础声明缺省为 normal；父行/父列百分比、指定父项百分比、累计百分比及两种排名保存为 `dataField/extLst/ext/x14:dataField@pivotShowAs`，扩展 URI 为 `{E15A36E0-9728-4e99-A89B-3F7291B0FE68}`，命名空间为 `http://schemas.microsoft.com/office/spreadsheetml/2009/9/main`。基础模式与扩展冲突、未知属性/内容、其他扩展及原生值格式保持保护，原样保存仍保留源。

subtotals 是需要自动小计的外层行/列字段索引集合，空数组关闭小计；展开后的末层字段、重复项及非轴字段拒绝。小计位于所属组之后，采用值字段各自的聚合，直接读取筛选后的原始记录；行列小计交叉格与总计不再次累加显示结果。原生字段保存 defaultSubtotal、subtotalTop=0 及默认小计项，rowItems/colItems 保存 default 类型、字段深度及值字段索引。已有设置可加载、预览、修改和关闭，沿同一扩大保护、缩小清理与精确历史；重开刷新仍可用。上方小计、自定义小计聚合及其他未知布局保持保护。预览行与列成员新增 subtotal 布尔值，小计的 members/formats 只含所属字段前缀；UI 为剩余行字段补空表头格。原生标题沿源格式生成，预览继续保留原始类型。输出矩阵及分组预算包含小计，聚合工作量在累积前检查。实现依据 [ONLYOFFICE 小计项生成](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L5569-L5600)、[字段小计项](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L17035-L17065)和[格式化标题](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/Workbook.js#L11195-L11215)。

`Session::pivots(revision, sheet)` 返回 `{ revision, items }`。每项包含 part、name、range、sourceSheet、source、stale、settings 和 reason；不支持的原生定义返回 null settings 和保护原因。`Session::refresh_pivot(revision, sheet, part)` 重新读取当前计算值，整体替换缓存、记录、定义和输出。源值或依赖公式变化在普通事务中写入缓存失效标志；普通输入不自动刷新结果。结果格拒绝普通值/公式写入。刷新扩张必须有空白空间，缩小清空移出的结果格，保持区域外内容；旧位置内的直接格式保留。相同源与结果的刷新不新增历史。创建、源数据失效和刷新各用现有 revision、有界部件历史和包校验，保存重开后仍可刷新。

aggregate 接受 `sum`、`count`、`countNums`、`average`、`min`、`max`、`product`、`stdDev`、`stdDevp`、`var` 和 `varp`。count 统计非空记录，countNums 只统计数值。文字与布尔值不加入数值聚合，错误值沿数值结果传播；平均值和样本/总体统计按有效数值数目处理。规则依据 [ONLYOFFICE 聚合状态](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/FormulaObjects/databaseFunctions.js#L51-L220)、[类型与大小写缓存](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L3075-L3184)和[原生行列项](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L5289-L5620)。

源最多 64 列、65536 个数据格，共享项及输出文字各最多 1 Mi UTF-16；行/值字段各为 1–8 项，列字段为 0–8 项，两轴各最多 4096 个明细/小计项，输出最多 32768 格。新建总数最多 16 项；导入目录读取最多 64 项。聚合及普通事务检查各受 1048576 项工作量、4 MiB 历史及包预算约束。输出与源、合并或结构化区域相交时拒绝，扩张时也保护便笺和链接。支持的刷新范围是原生普通区域行列轴、固定或自动数值边界分组、单级或多级日期分组及纵向报表筛选定义；横向或换行分页字段、手动成员顺序、扩展头部、未知源标记及属性继续保护。源标题变更需要字段映射，当前拒绝刷新；不能解析的源范围保护单元格编辑。样式及更广导入兼容继续实施，共享缓存范围沿上述协调事务。布局归 [`pivot-layout.mbt`](../../../modules/formats/src/xlsx/pivot-layout.mbt)，其余实现归 [`pivot-cache.mbt`](../../../modules/formats/src/xlsx/pivot-cache.mbt)、[`pivot.mbt`](../../../modules/formats/src/xlsx/pivot.mbt)、[`pivot-refresh.mbt`](../../../modules/formats/src/xlsx/pivot-refresh.mbt)、[`pivot-protection.mbt`](../../../modules/formats/src/xlsx/pivot-protection.mbt)、[传输校验](../../../packages/xlsx/src/core/xlsx-pivot.ts)和[默认面板](../../../packages/xlsx/src/react/xlsx-pivot.tsx)。

### 原生时间线目录

`SpreadsheetEditor.objects.timelines()` 返回当前工作表的原生时间线目录 `{ revision, sheet, reason, items }`。同步 `XlsxSession` 和 Worker `XlsxClient` 使用 `execute({ operation: "timelinesXlsx", revision, sheet })`，MoonBit 入口为 `Session::timelines`。查询无需字体，不刷新透视结果，也不改文档、revision、选择、历史或重做。默认面板提供读取、源字段、可用/所选日期和关联透视表详情；目录随文档和工作表切换重置，过期目录提示重新读取。详情可在受保护的编辑控件之外读取。

每项包含视图部件、名称/标题、缓存部件/名称、源字段、独立日期 PivotCache 和零基字段索引，以及关联表的工作表/部件/名称/字段身份。`level` 与 `selectionLevel` 分别记录显示及选择粒度，0–3 对应年、季度、月、日。保留四项显示开关、样式名和可选滚动时间。`state` 包含 `{ bounds, selection, singleRange, filterType, minimumRefreshVersion, lastRefreshVersion }`；范围为 `{ start, end }` 原生 ISO 时间串，selection 为 null 时没有选区声明。目录保留非连续状态及过滤类型，不据此推算或应用筛选。

核心校验工作表/工作簿扩展、原生关系与内容类型、缓存角色、源字段和同源透视连接。日期缓存可从工作簿的 `timelineCachePivotCaches` 扩展目录解析，与结果表缓存分开；原生 `timelineData` 标志不能互换。缓存和视图名称按大小写无关身份连接。重复或失联引用、外部/OLAP 源、未知元数据、角色/来源冲突或非法日期返回原因与空目录；资源超限继续抛错。每表最多 64 个视图，每类部件引用最多 64 项，每缓存最多 16 个连接、最多 80 个缓存字段，视图及时间线缓存 XML 合计限 1 Mi UTF-16 单元，目录输出同限。名称、标题及样式最多 255 单元。日期沿既有日历解析，接受可选 Z 和小数秒；时区偏移和日历下界之前的日期继续保护。

读取依据 [ONLYOFFICE Timeline.cpp](https://github.com/ONLYOFFICE/core/blob/3250a848ee4ef20c2fb8c38dc86350ec579124b8/OOXML/XlsxFormat/Timelines/Timeline.cpp)、[工作簿扩展](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-xlsx/e29966e2-5baa-4fcf-84c9-082025e1be13)、[缓存角色](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-xlsx/d49705e6-4e25-4573-9b14-6b666a6e0bb1)和 [CT_Timeline](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-xlsx/0d578770-103b-4d74-8920-6636997b6424)。实现归 [`timeline-source.mbt`](../../../modules/formats/src/xlsx/timeline-source.mbt)、[`timeline.mbt`](../../../modules/formats/src/xlsx/timeline.mbt)及 [`xlsx-timelines.tsx`](../../../packages/xlsx/src/react/xlsx-timelines.tsx)。未复制上游源码。

原生 `timeslicer` 绘图已接入 R0 Canvas 和打印/PDF。核心读取固定、随单元格移动及随单元格缩放三类锚点，也读取 a15 兼容分支，保留原生后备。按 `level` 绘制年、季度、月或日刻度，使用原生日期范围、滚动位置及连续选区；月份按真实日历划分，保留小数秒。标题、选区文字、粒度和滚动条分别遵循原显示开关。沿工作簿普通/粗体字体测量，每个控件最多绘制 512 个可见日期段，不遍历整个日期跨度。绘制、目录查询及保存重开不增加文档历史。

视口对象以 `kind: "timeline"` 返回 `timeline: { name, label, frame, move, periods, navigation, handles }`。默认宿主提供日期范围分组、原生选区说明及具名日期按钮，遮挡底层单元格命中，并提供独立的标题移动与角点缩放控件。打印仅识别已校验的时间线、切片器及迷你图扩展；混合未知内容继续保护。行高、列宽变化时，原生框与已校验的平面兼容后备随单元格同步移动或缩放。普通图片/形状的属性、复制及删除入口继续拒绝时间线；原生时间线使用下述协调框编辑与删除事务。

首批支持默认样式及 `TimelineStyleLight1`，使用工作簿文字色与强调色。精确的原生预设差异格式及几何尚未匹配，不能视为原生样式保真；其他预设、自定义覆盖及非连续选区继续保护。实现归 [`timeline-drawing.mbt`](../../../modules/formats/src/xlsx/timeline-drawing.mbt)和 [`timeline-paint.mbt`](../../../modules/formats/src/xlsx/timeline-paint.mbt)，日期含义依据 [CT_TimelineState](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-xlsx/aa9bf132-1afa-4ce9-b3d2-e6dc00e48fde)。精确样式继续实施；原生日历分组映射见下文。

`editSheet({ action: "filterTimeline", name, range })` 筛选当前工作表的原生时间线。range 为 `{ start, end }` 原生 ISO 时间串或 null；MoonBit 入口为 `Session::filter_timeline(revision, sheet, name, range)`，range 使用可选日期串对。区间两端包含在内，必须有序且落在原生 bounds 内；保留小数秒。null 清除条件，写入 `filterType=unknown` 并移除 selection；明确范围写入 `dateBetween`。同缓存视图立即共享选区，清除后画布显示全部可用日期。默认面板提供开始/结束日期、应用和清除，使用既有编辑队列与输入提交屏障；日期表单按所选整日生成区间，边界日取原生 bounds。画布日期条使用下述点击及连续拖选入口。

范围按工作簿的 1900/1904 日期系统转换为各关联透视缓存的日期成员，在一个事务中更新原生隐藏项、结果格和时间线 state。读取原生日期/空白成员，保留其他字段条件、各表字段布局，以及关联切片器成员状态。结果缓存和独立日期缓存不重建，不刷新待处理源；输入值及原有过期标记保留。没有成员的区间写入空选择，返回空结果和空白总计；清除恢复全部缓存成员。各表输出变化累计最多 65536 格，任一表扩张冲突或保护失败都保留原包、选择、历史和重做；重复操作不添加历史。默认输入和结果区打印允许已校验的时间线连接元数据，未知扩展继续保护，手动锚点写回使用专用框编辑入口。

当前范围筛选支持工作表来源的未分组日期字段及既有原生日历分组。核心先按时间线原始日期区间筛选记录，再沿已有年/季度/月/日映射聚合；分组隐藏项只表示可见标签，不能代替原始日期条件。同月不同日及跨年份同名月份不会混入结果。条件从原生时间线 state 恢复，不裁剪缓存记录；切片器无数据状态使用其他字段的原始记录条件，排除自身字段的成员和日期条件。实现归 [`timeline-group.mbt`](../../../modules/formats/src/xlsx/timeline-group.mbt)。非连续状态、额外原生过滤器、数字/手工分组、衍生字段作为时间线来源继续保护。同字段切片器写入仍需时间线协调；透视表删除使用下述连接与资源事务。实现归 [`timeline-edit.mbt`](../../../modules/formats/src/xlsx/timeline-edit.mbt)，原生日期到成员的含义依据[时间线与透视视图连接](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-xlsx/576e7fb8-2352-4f8a-a541-08c2d4ba8887)。

同一透视日期字段可连接多个受支持时间线缓存。范围操作沿共同报表/字段扩展到整条连接链，逐项去重；不同工作表的视图保留各自原连接与显示设置，同步绝对日期选区。候选会话先同步选区，再按原始记录筛选日历分组，避免旧区间或同一字段重复过滤。缓存筛选保留记录和待刷新源；结果、相关切片状态及全部选区合为一项精确历史。连接链合计最多 16 张报表，仍沿用 65536 个输出格及元数据预算，后一张表失败时整项回滚。

显式刷新要求重叠连接的绝对日期条件一致；不同日期串表示相同时刻时视为同一条件。冲突状态保留原文，用户可显式用时间线范围入口统一该连接链后再刷新。非连续状态及额外原生过滤器继续保护。实现归 [timeline-filter-group.mbt](../../../modules/formats/src/xlsx/timeline-filter-group.mbt)、[timeline-group.mbt](../../../modules/formats/src/xlsx/timeline-group.mbt)及[原协调刷新](../../../modules/formats/src/xlsx/timeline-refresh.mbt)。受支持连接图的整表复制沿[工作表复制](xlsx-editing.md#工作表顺序名称与可见性)维护独立控件定义及原始数据缓存。

`SpreadsheetEditor.objects.insertTimeline(settings)` 在当前选择处创建原生时间线。同步 `XlsxSession` 与 Worker `XlsxClient` 使用 `execute({ operation: "insertXlsxTimeline", revision, sheet, settings })`；MoonBit 入口为 `Session::insert_timeline`。`XlsxTimelineSettings` 包含透视表部件 `pivot`、零基源字段 `field`、`name`、`caption` 及 point 单位的 `width`/`height`。默认面板提供透视表、字段与尺寸输入，使用既有编辑队列和输入提交屏障。

创建读取原缓存，不刷新待处理源。支持未分组或既有原生日历分组、索引记录的日期字段：原生日期成员，或源列采用受支持日期格式的数字成员；保留空白及成员索引。独立日期缓存复制记录并设置原生日期角色，结果缓存只将所选日期字段转换为原生日期；同结果缓存的其他透视表保持可读。相同字段连接复用时间线缓存。现有连续日期条件继承为原生选区；分组条件先映射回原始日期，所选成员须构成连续日期区间。非连续或空成员、空白/越界分组标签条件继续保护。新控件采用月粒度、Light1、随单元格移动锚点和兼容后备，全部部件与连接合为一项精确历史。

名称、日期字段、字体或资源预算失败保留原包和重做。数字日期沿工作簿的 1900/1904 系统转换；1900 系统三月之前的数字日期继续保护，待实现虚构闰日映射。支持范围及精确样式边界同上，关联日期字段的分组修改与源列映射见下文。创建实现归 [`timeline-create.mbt`](../../../modules/formats/src/xlsx/timeline-create.mbt)。

`editSheet({ action: "deleteTimeline", name })` 删除当前表的原生时间线；MoonBit 入口为 `Session::delete_timeline(revision, sheet, name)`。同步 Wasm、Worker 和默认删除按钮共用既有编辑队列与事务。删除整个原生或兼容绘图框；同视图部件中的其他控件保留。最后一项删除时，清理独占视图部件、工作表引用、关系及内容类型项，保留独立绘图容器及其他绘图。

删除保留当前透视结果、筛选、待刷新源和选择；一项历史精确恢复全部资源。最后一个可见控件删除后，原生时间线缓存、独立日期缓存及连接继续承载原有日期条件。保存重开后透视表保持可读，重新创建同字段时间线复用该缓存和选区。锁定、受保护工作表、共享或扩展资源、引用注释及旧 revision 原子拒绝。实现归 [`timeline-delete.mbt`](../../../modules/formats/src/xlsx/timeline-delete.mbt)及共用 [`slicer-delete.mbt`](../../../modules/formats/src/xlsx/slicer-delete.mbt)。

关联时间线的透视表沿用 `editSheet({ action: "deletePivot", part })` 和默认“删除透视表及结果”入口。还有连接时，只移除目标透视连接，保留全部视图、日期状态、独立日期缓存及其他表的原结果与条件；剩余时间线可继续筛选。最后一个连接删除时，清理各工作表中的所属视图与绘图、时间线缓存，以及不再被其他时间线引用的独立日期定义和记录。支持普通 `pivotCaches` 和原生扩展日期目录，保留共享日期定义、共享记录流及无关资源。

缓存中的原生日期成员继续按工作簿日期系统校验和读取，不要求仍有时间线连接。未连接的共享结果表在时间线清理后保持可读、可重开及刷新。输出、连接和跨表资源合为一项精确历史，保留待刷新源；任一远端工作表保护、引用注释、共享资源身份或预算失败都保留原包、选择和重做。最多清理 256 个关联视图，扫描的视图及保留缓存元数据合计最多 1 Mi UTF-16 单元。实现归 [`timeline-pivot-delete.mbt`](../../../modules/formats/src/xlsx/timeline-pivot-delete.mbt)和 [`timeline-delete-cache.mbt`](../../../modules/formats/src/xlsx/timeline-delete-cache.mbt)，参考 [ONLYOFFICE deleteTimelinesByPivotTable](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/Workbook.js#L5430-L5438)。

关联时间线的透视表沿用 `editSheet({ action: "refreshPivot", part })` 和默认“刷新透视表”入口。核心沿结果缓存、透视连接及共享独立日期缓存收集整条连接链，按当前源重建全部关联结果、原生日期定义和记录，清除过期标记。更新原生 bounds，保留绝对 selection、粒度、滚动位置及视图源；新日期按原选区自动选中。清除状态继续选择全部当前日期。其他字段条件和切片器选中成员保持，缺失成员保留身份并同步无数据状态。

结果缓存继续写原生日期共享项，独立日期缓存保留原生角色及部件身份。选区完全离开新的可用日期时，保留选区并产生空结果；用户仍可清除条件。一次刷新最多覆盖 16 张连接表、65536 个变化结果格，全部缓存与结果合为一项精确历史；相同源与设置不增加历史。后一张表扩张冲突、非日期或全空日期源、未知日期缓存元数据、只读计算状态及资源预算失败保留原包、源值、选择与重做。共享独立日期定义进入协调范围，记录流存在额外共享别名时继续保护。既有日历分组保留原始日期筛选，源扩展及预览沿同一条件处理新增日期。独立日期缓存读取原始字段及已校验分组字段形态；刷新时统一写回原始源字段，不携带报表衍生分组，保留缓存和记录部件身份。原分组先经已有解析器校验，未知标签不会被静默丢弃。1900 系统早期数字日期仍待实现；源列映射沿下述显式源修改事务。实现归 [`timeline-refresh.mbt`](../../../modules/formats/src/xlsx/timeline-refresh.mbt)和 [`timeline-refresh-source.mbt`](../../../modules/formats/src/xlsx/timeline-refresh-source.mbt)，共用 [`pivot-cache-profile.mbt`](../../../modules/formats/src/xlsx/pivot-cache-profile.mbt) 保留原有元数据校验。

关联时间线的字段与源修改沿用 `editSheet({ action: "updatePivot", part, settings, sourceRevision })` 和默认字段面板。目标表可调整行列字段、值字段顺序/聚合/标题及小计，其他表保留自己的设置。源范围可扩大、缩小或迁移至其他工作表；同名原始列可重排、添加或删除未用列。日期分组修改遵循下述共享缓存事务。新来源同步整条时间线连接链的结果及独立日期缓存，保留部件身份、绝对日期选区和原源格。结果与资源共用一项精确历史，相同定义与数据不增加历史。

时间线继续管理日期条件，源中的新日期按其绝对选区选择。对该字段提交相同成员集合允许调整顺序；实际改变或移除日期条件须使用时间线范围入口，不能由字段修改静默覆盖。布局外的其他成员条件须连接该表的原生切片器或时间线。仍被引用的列删除或改名、歧义标题、未连接条件、不支持的分组改写、过期预览和任一表扩张失败保持原包、选择与重做。

显式源修改按原始列标题映射字段身份。目标表的完整 settings 使用新源编号，关联表自动重映射行列、值、基准字段、小计、条件及分组；每张表保留自身条件。切片器和时间线按原生 sourceName 连接新编号，保留缓存身份、绝对日期区间和视图原文。独立日期缓存按旧源宽度校验已有记录，再写新源字段。默认面板在修改源范围后保留正在重映射的成员选择，预览继续由核心校验日期条件。新源标题必须唯一且可定位被引用原列；无连接、字段或条件引用的列允许删除。仅含切片器的共享缓存沿上述同名列映射；删除被使用源列仍待接通。实现归 [`pivot-source-fields.mbt`](../../../modules/formats/src/xlsx/pivot-source-fields.mbt)及上述刷新事务；字段身份沿 [ONLYOFFICE _updateCacheDataUpdatePivotFieldsIndexes](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L6619-L6650)。

关联日期源字段可沿 `updatePivot` 修改 `dateGroups`，添加、更换或移除既有年/季度/月/日分组。默认字段面板继续使用日历单位、预览和应用入口。目标结果缓存的全部共享透视表同步分组定义，保留各自行列和值设置；独立结果缓存保留自己的分组。原始日期区间和视图源保持不变，先筛选原始记录，再生成新的分组项和衍生字段。源字段身份、其他字段条件、同字段切片器成员与无数据状态、缓存及结果合为一项精确历史；无变化不新增历史。仅修改当前缓存中已连接时间线的原始日期列，数字分组、未关联字段和手工/未知分组继续保护。实现复用 [`timeline-refresh.mbt`](../../../modules/formats/src/xlsx/timeline-refresh.mbt) 与 [`slicer-state.mbt`](../../../modules/formats/src/xlsx/slicer-state.mbt)；原字段与衍生字段处理参考 [ONLYOFFICE groupRangePr/ungroupRangePr](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/PivotTables.js#L1884-L1916)。

编辑预览使用 `SpreadsheetEditor.objects.pivotPreview(settings, part?)`；同步与 Worker 客户端的第三个参数同为可选透视表部件身份，核心为 `Session::pivot_preview(revision, settings, part=...)`。默认编辑面板自动传入身份，按时间线实际选区预览新源日期；省略身份用于创建预览。返回的 settings 保留用户草稿，分组结果和包含记录数使用有效日期条件。预览不改源、revision 或历史，只读计算状态和失联身份在核心拒绝。字段/源应用继续复用 [`timeline-refresh.mbt`](../../../modules/formats/src/xlsx/timeline-refresh.mbt)。

`SpreadsheetEditor.objects.setTimelineFrame(id, frame)` 修改原生时间线框；同步 `XlsxSession` 与 Worker `XlsxClient` 使用 `execute({ operation: "frameXlsxTimeline", revision, sheet, id, frame, profile })`，核心为 `Session::set_timeline_frame`。与切片器共用 `XlsxDrawingFrame`：仅含 `anchor/x/y/width/height`，三种锚定和坐标、尺寸边界同切片器。当前框从已测量视口的 `object.timeline.frame` 读取，折叠框可读零尺寸；提交要求有效正尺寸。默认时间线面板提供数值编辑，沿输入屏障和串行队列应用。

框编辑只修改绘图，保留时间线身份、日期状态、缓存、记录、透视结果和待刷新源。原生框与已校验的平面兼容后备同步变换，保留 clientData；直接原生框也可编辑。一项历史精确恢复资源，相同框不增加历史。绘图锁、受保护或隐藏工作表、未知后备、变换/锚点注释和缺失字体保护原包与重做。实现复用 [`analysis-frame.mbt`](../../../modules/formats/src/xlsx/analysis-frame.mbt) 和 [`xlsx-analysis-frame.tsx`](../../../packages/xlsx/src/react/xlsx-analysis-frame.tsx)。画布标题拖动与四角缩放复用 `selectDrawing`、`drawingGesture` 及上述框事务。核心返回最多四个窗格的 `move` 区域，排除右侧日期粒度及下方日期条；隐藏标题时使用 3.6 磅顶边。选择锁、未知后备或变换注释隐藏拖动区；具体移动、缩放和比例锁继续在核心校验。

指针候选不改文档、revision、单元格选择或历史，抬笔提交一项变化，Escape 取消并恢复原画布。冻结、RTL 和边缘滚动共用既有坐标换算；方向键移动 1 磅，Shift 方向键移动 10 磅，角点聚焦时调整该角尺寸。Delete 使用协调的 `deleteTimeline`，保留缓存和筛选，撤销恢复完整视图资源。复制、剪切和层次调整继续保护。宿主复用 [`spreadsheet-drawing-pointer.ts`](../../../packages/xlsx/src/web/spreadsheet-drawing-pointer.ts)，日期条交互见下文。

画布日期条支持单周期点击、连续拖选，以及 Enter/Space 键盘选择。`periods` 包含核心生成的 `{ index, label, selected, regions }`，最多 512 个可见日期段，每段最多四个窗格区域。年、季度、月、日沿同一绘制与命中几何；标识由调用方原样回传，不自行推算日期。选择锁隐藏日期按钮，受保护的缓存状态继续在筛选事务中拒绝。

同步 `XlsxSession` 与 Worker `XlsxClient` 使用 `execute({ operation: "timelineGestureXlsx", revision, layout, id, gesture, profile })`；gesture 为 `{ handle, first, position, x, y, commit }`；handle 为 0 时选择范围，1/2 时调整开始/结束端点，first 固定为按下时可见起始段或端点的周期标识。position 使用导航元数据中的首周期标识，须在 minimum–maximum 内，点使用当前视口坐标。核心验证 revision、布局和目标，终点取 position 对应候选窗口中最近的可见段，支持反向拖选及跨窗口保留原起点。范围按整周期与原生 bounds 相交，排除下一周期的零点并保留可表示的小数秒。候选返回 `{ query: null, drawing }`，不改原包、选择、revision、历史或重做；释放返回 `{ query, drawing: null }`，筛选、结果和目标视图的 `selectionLevel` 合为一项历史。其他视图保留自己的显示及选取粒度。

核心入口为 `Session::timeline_gesture`，与 `Session::filter_timeline` 共用内部筛选事务。共享视图与所有原生连接使用已有缓存，保留待刷新源；空周期产生空结果，相同范围及粒度不增加历史。Escape、失焦或视口滚动取消候选，返回当前画布；日期交互期间隐藏框手柄。宿主提供提交后的 `aria-pressed` 状态和返回网格的 Escape。实现归 [`timeline-pointer.mbt`](../../../modules/formats/src/xlsx/timeline-pointer.mbt) 及 [`spreadsheet-slicers.ts`](../../../packages/xlsx/src/web/spreadsheet-slicers.ts)。`selectionLevel` 含义沿上述 CT_Timeline 合同；日期条和两个端点在边缘停留时每 120 毫秒滚动一个周期，到原生边界停止；计时器不堆积请求。候选滚动与筛选保持隔离，抬笔合为一项历史，Escape、失焦及宿主滚动取消并停止计时。宿主日期手势归 [`spreadsheet-timeline-pointer.ts`](../../../packages/xlsx/src/web/spreadsheet-timeline-pointer.ts)；端点、粒度和滚动设置见下文。

`editSheet({ action: "setTimelineLevel", name, level })` 修改目标视图的显示粒度，0–3 对应年、季度、月、日。默认时间线面板与画布下拉框沿现有输入屏障和队列提交。保留绝对 `scrollPosition`、日期筛选及 `selectionLevel`；共享视图继续使用自己的显示设置。

`editSheet({ action: "scrollTimeline", name, level, position })` 修改该视图的首个可见周期。position 使用核心导航元数据的周期标识，须落在 minimum–maximum 内；level 须仍等于目标当前粒度，拒绝旧滑块事件。新位置写该周期起点，起始周期保留原生 bounds 的实际起点；当前周期不变时保留原时间串，不新增历史。滚动只改视图，不筛选或刷新数据。核心入口为 `Session::set_timeline_level` 与 `Session::scroll_timeline`，实现归 [`timeline-view.mbt`](../../../modules/formats/src/xlsx/timeline-view.mbt)。

`navigation` 包含 `{ level, minimum, maximum, position, label, levelRegions, scrollRegions }`。核心按原生开关及选择锁返回最多四个窗格区域；宿主用完整框和裁剪区放置原生下拉框及滑块，滑块以 label 提供可读日期说明。拖动释放或键盘改变位置后提交一项历史；日期选择、缓存、待刷新源、其他视图及工作表内容保持。保护/隐藏工作表、只读计算状态、旧 revision、非法粒度与位置原子拒绝。保存、撤销和重开保留视图设置，随后日期选择继续使用当前布局；滑块拖动中不创建文档候选。具有可见滚动区的时间线按横/纵滚轮的主方向逐次移动一个周期，队列在执行时读取当前位置；到边界不增加历史或消耗重做。滚轮取消日期候选，保留日期条件、缓存及待刷新源；日期按钮离开窗口时，焦点留在控件内。Ctrl+滚轮沿平台行为，隐藏滚动区及选择锁不拦截。

端点调整已接入核心和默认宿主，指针拖动、取消及键盘定位已有定向检查。`handles` 返回可见端点的 `{ handle, index, value, regions }`。指针按当前粒度调整端点并保留另一端的精确时间；键盘沿 `editSheet({ action: "setTimelineEndpoint", name, handle, level, position })` 调整，核心入口为 `Session::set_timeline_endpoint`。键盘跨窗口定位及指针边缘停留均沿核心调整滚动位置，与筛选共用一项历史。同周期操作保留原时间串及历史。刷新缩小 bounds 后，调整一端可保留另一端未改变的原生时间串；普通范围入口仍要求两端位于 bounds 内。相关实现归 [`timeline-endpoint.mbt`](../../../modules/formats/src/xlsx/timeline-endpoint.mbt) 和 [`spreadsheet-timeline-endpoints.ts`](../../../packages/xlsx/src/web/spreadsheet-timeline-endpoints.ts)。

### 打印与资源边界

工作表绘图以纸张宽度作右到左镜像基准。裁剪端点先沿原逻辑轴量化，再镜像到纸张。左右不等边距、50%/100%/150% 比例和显式打印区域的独立控制覆盖三种锚点，完整 Canvas/PDF 对照范围见[测试说明](../testing.md#当前兼容证据入口)。依据固定原生版本的[绘图打印变换](https://github.com/ONLYOFFICE/sdkjs/blob/3679e0375a758d7dc59d31337a45461be3525ed8/cell/view/WorksheetView.js#L4364-L4390)及[先量化后镜像的裁剪](https://github.com/ONLYOFFICE/sdkjs/blob/3679e0375a758d7dc59d31337a45461be3525ed8/cell/view/WorksheetView.js#L4402-L4413)，实现归 [`print.mbt`](../../../modules/formats/src/xlsx/print.mbt)。单元格保持自身的打印边距与布局规则。原生自动绘图打印范围的部分裁切差异继续单列。

图表页打印将绘图原点换算为物理毫米，向零截断到十万分之一毫米，再换回逻辑坐标。规则依据 [ONLYOFFICE 元文件数值精度](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/common/Drawings/Metafile.js#L671-L679)及[变换写入](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/common/Drawings/Metafile.js#L2287-L2305)，实现归 [`chart-sheet-print.mbt`](../../../modules/formats/src/xlsx/chart-sheet-print.mbt)。四份不同页边距、两种拟合比例的独立控制，其正常导出的完整 PDF 均为 0/0，源保存逐字节相同。此项只调整图表页打印原点；工作表打印及网格视图使用各自规则。屏幕纹理和原件的完整视觉范围见[测试说明](../testing.md#当前兼容证据入口)。

绘图的右边或下边恰好贴合行列边界时，占用范围止于前一个可见格。零宽高线仍保留锚点所在格。网格滚动范围与打印共用这项规则，避免多出只有尾端边界的一页。

工作表绘图的打印原点包含页边距内一个 96 dpi 网格像素，即缩放前的 0.75 pt。图片、形状、图表和分析控件共用这项偏移；源锚点、编辑坐标和网格视图保持。规则依据 [ONLYOFFICE 打印字段](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/view/WorksheetView.js#L3266-L3269)与[绘图变换](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/view/WorksheetView.js#L4170-L4192)。十二份显式区域独立控制覆盖三个比例、两个方向及边距互换，Canvas/PDF 均为 0/0；原生自动绘图范围的裁切差异仍单列。完整状态归[测试说明](../testing.md#当前兼容证据入口)。

绘图打印裁剪使用缩放后的物理坐标。左、上端点按 96 dpi 截断，右、下端点按同一像素网格舍入；两端再保留十万分之一毫米的元文件精度，最后换回逻辑坐标。图片、形状、图表和分析控件共用这项裁剪，单元格保持自身规则。依据固定原生版本的[端点量化](https://github.com/ONLYOFFICE/sdkjs/blob/3679e0375a758d7dc59d31337a45461be3525ed8/cell/view/WorksheetView.js#L4433-L4436)、[像素换算](https://github.com/ONLYOFFICE/sdkjs/blob/3679e0375a758d7dc59d31337a45461be3525ed8/cell/graphics/pdfprinter.js#L480-L486)及[元文件精度](https://github.com/ONLYOFFICE/sdkjs/blob/3679e0375a758d7dc59d31337a45461be3525ed8/common/Drawings/Metafile.js#L671-L677)，实现归 [`print.mbt`](../../../modules/formats/src/xlsx/print.mbt)。独立原始尺寸面积图控制的整页 PDF 已为 0/0，Canvas 仍有余差；完整原件及右到左边界见[测试说明](../testing.md#当前兼容证据入口)。

工作表的空 `phoneticPr` 默认设置可保留并打印。核心校验唯一节点、字体表索引、四种转换类型和四种对齐值，默认设置本身不生成注音文字。未知属性、子节点、文本、重复声明和非法字体索引继续保留诊断并保护打印；含实际 `rPh` 注音文本的单元格仍沿原有保护。设置在单元格编辑、精确历史和保存重开后保持。该规则不新增注音文字排版或编辑 API，独立原生对照与 C43 整页输出范围见[测试说明](../testing.md#当前兼容证据入口)。

原生 `pageSetup` 的打印机 `r:id` 作为保留数据处理。SDK 按已支持的纸张、方向和边距打印，并保留原关系和打印机部件。纸型代码 `0` 使用既有 A4 默认值。未知属性、纸型、错误命名空间及空关系身份继续拒绝。

`editSheet({ action: "pageSetup", paper, orientation, left, top, right, bottom, scale, fitWidth, fitHeight })` 保存当前工作表的打印设置。`XlsxPrintSetup` 的纸张为 `A4` 或 `Letter`，方向为 `portrait` 或 `landscape`，边距为 point。边距须非负并在每个方向留下至少 12 pt 可打印空间；比例为 10–400 的整数，横/纵页数为 0–1024 的整数。0 表示该方向不限页数；任一页数非零时取代百分比。核心先按原生规则预留标题尺寸和一个网格像素，将所需比例四舍五入并限制为 10%–100%；再按实际行列及重复标题检查页数，必要时降低整数比例。10% 仍不能满足时输出失败，不截断内容。页面与缩放范围参考 [ONLYOFFICE calcPrintScale](https://github.com/ONLYOFFICE/sdkjs/blob/3679e0375a758d7dc59d31337a45461be3525ed8/cell/view/WorksheetView.js#L4788-L5020)。

读取工作表时，旋转 A4 代码 `77` 按 297 × 210 mm 的基准尺寸应用源方向。打印可读取显式关闭的黑白、草稿和批注选项。[纸张代码](https://learn.microsoft.com/zh-cn/windows/win32/intl/paper-sizes) [LibreOffice 纸张方向](https://github.com/LibreOffice/core/blob/bf6ef2662401c7d6dce671ab4deb26ee0af3a7c1/sc/source/filter/oox/pagesettings.cxx#L928-L957)

`XlsxQuery.printSetup` 返回上述设置及 `readOnlyReason`。修改 `pageMargins`、`pageSetup` 和 `sheetPr/pageSetUpPr`，按 XML 顺序创建缺失节点，保留其他部件、单元格、公式缓存及计算链。边距写回 inch，查询和排版统一使用 point；新页边距包含 header/footer 的标准字段。一次设置一项历史，保持选择，重复设置不增加历史。保护、旧 revision、未知打印属性或预算失败保持源和历史。未知设置返回保护原因，其查询字段使用默认值占位，不能视为源文件的实际设置。

`editSheet({ action: "printRange", area, rows, columns })` 保存打印区域及重复标题。`area` 使用当前表 A1 矩形，多个矩形以逗号分隔（如 `A1:D20,F1:H20`），最多 32 项和 2048 UTF-16 单元；`rows` 使用整行区间（如 `1:2`），`columns` 使用整列区间（如 `A:B`），各最多 32 UTF-16 单元。各字段留空即清除该设置。接受绝对引用和小写列名，核心返回规范形式并保留区域顺序。`XlsxQuery.printRange` 返回这三个字段及 `readOnlyReason`，类型为 `XlsxPrintRange` 加保护原因。受保护源的空字段是查询占位，不能当作实际设置。

核心写入 `workbook/definedNames` 中带 `localSheetId` 的 `_xlnm.Print_Area` 和 `_xlnm.Print_Titles`，保留其他名称、已有名称属性、工作表源及计算缓存。每个区域分别写入带表名的绝对引用；导入的同表多区域定义使用同一路径。改名、复制、重排、删除及行列结构变化沿已有名称引用事务同步；名称中的空格、逗号和单引号按工作表引用规则处理。一次设置一项精确历史，重复设置不新增历史；旧 revision、表/工作簿结构保护及源/输出预算失败原子拒绝。重复或无作用域的打印名称、跨表定义和含未知内部标记的定义继续保护。

多个区域按定义顺序分别起页，不按地址排序、合并或去重；相交格会随各区域分别打印。各区域复用标题，每表共用满足全部区域页数设置的最大缩放比例；百分比模式保持指定比例。页码和首页/奇偶模板在同表区域之间连续，切表才重新开始。该规则参考 [ONLYOFFICE 多区域分页](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/view/WorksheetView.js#L3795-L3914)及[共用缩放](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/view/WorksheetView.js#L4698-L4735)。

重复标题只补当前页起点之前的行列，和正文重合时绘制一次。标题可在打印区域之外；隐藏行列保持隐藏。分页和适合页数都预留标题尺寸，过大的标题明确失败；不截掉标题来满足页数。该行为参考 [ONLYOFFICE 打印标题分页](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/view/WorksheetView.js#L3286-L3390)及[名称写回](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/view/WorksheetView.js#L23501-L23556)。

`editSheet({ action: "headerFooter", ...settings })` 保存纯文字页眉页脚，查询为 `XlsxQuery.headerFooter`，类型为 `XlsxHeaderFooter` 加 `readOnlyReason`。设置包含六个字符串 `oddHeader/oddFooter/evenHeader/evenFooter/firstHeader/firstFooter`，四个布尔值 `differentFirst/differentOddEven/scaleWithDoc/alignWithMargins`，以及 point 距离 `headerMargin/footerMargin`。默认六段为空，首页/奇偶页不区分，随表缩放并对齐边距，距纸张上/下边缘均为 21.6 pt。距离可设 0–14400 pt，实际文字越出纸张时打印失败。

每段最多 255 UTF-16 单元；留空清除。支持 `&L`、`&C`、`&R` 切换左、中、右部分，`&P` 为页码，`&N` 为本次输出总页数，`&A` 为当前表名，`&&` 为普通 `&`。未指定部分时居中，支持换行，CR/CRLF 规范为 LF。文字使用工作簿 Normal 字体、字号和黑色。字体、装饰、图片、日期/时间及文件字段控制码暂时保护，不能静默丢弃。源 `useFirstPageNumber/firstPageNumber` 可指定正整数页码起点；首页与奇偶模板按实际输出页序选择，不随起始页码改变。字段与模板语义参考 [ONLYOFFICE HeaderFooter](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/model/HeaderFooter.js#L72-L123)及[页眉页脚绘制](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/view/WorksheetView.js#L5301-L5405)。

六段与标志写入工作表 `headerFooter`，距离写入 `pageMargins` 的 inch 字段。缺失节点按源顺序创建，保留其他边距、根注释、单元格、计算缓存和非目标部件；重复设置不增加历史。表保护、未知标记、旧 revision、预算失败均不提交部分结果。未知源查询返回保护原因和默认占位值。页眉页脚沿核心字体与有序图元输出，随表缩放时仍保留物理边距和距离；关闭边距对齐时使用 17.8 mm 左右边距。页眉页脚按保存的位置绘制，不移动正文；距离和正文边距可产生重叠，越出纸张则拒绝输出。默认 UI 和自定义 UI 使用同一事务与输出屏障。

`SpreadsheetEditor.printLayout()` / `exportPdf()` 默认传递 null，打印当前表并使用已保存的纸张、边距和缩放。没有源设置时，核心默认 A4 纵向、四边 36 pt 和 100%。默认范围优先使用各表保存的打印区域。没有定义时，工作表从 `A1` 打印到最后一个单元格或绘图边界，保留前导空行和空列。`PrintOptions` 可单独给出 `range`、`sheets`，或一起给出六个临时 point 纸张字段 `width/height/left/top/right/bottom`，纸张字段必须全部提供。`range` 支持相同上限的逗号分隔矩形，非空时替代保存的全部区域。临时纸张和范围应用到每个目标表，保存的缩放、重复标题及页眉页脚继续适用。`checkPrintOptions` 校验同一边界。[ONLYOFFICE 默认打印范围](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/view/WorksheetView.js#L3921-L3943)

`{ sheets: "visible" }` 打印全部可见表，`{ sheets: [id, ...] }` 打印指定的可见表，按当前工作簿顺序合并；列表顺序不改变工作簿顺序。列表须含 1–256 个不重复的稳定表身份，未知或隐藏表明确拒绝。各表保留自己的页面尺寸、缩放、打印区域、重复标题和页眉页脚。没有实际单元格、可打印绘图或打印区域的空表不生成页面；显式指定空白区域仍可打印。所有目标表均无可打印内容时，核心返回 `unsupported-print`，保留已有预览与源。页码起点及首页/奇偶模板在切表时重新开始，`&N` 使用整次输出的总页数。整体分页与字段语义参考 [ONLYOFFICE 工作簿打印](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/view/WorkbookView.js#L4144-L4200)及[切表后的页码](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/view/WorksheetView.js#L3978-L4002)。

多表共用 32768 格与 1024 页上限，不按表重新分配预算。绘图另计整次输出 1048576 个路径段、字形或其他图元，每页最多 262144 个绘图图元；图表页不占用单元格预算。任一目标表失败，整次输出失败，源、历史、活动表、选区及已有成功预览保持。`XlsxPrintLayout.sheet` 仍是请求时的当前表身份，不表示所有输出页来自同一表。默认 UI 提供全部可见表预览、跨表翻页、全部可见表 PDF 和当前表 PDF。导出其他范围时保留已显示的预览及其页码；PDF 不确认原 XLSX 已保存。

从左到右的工作表中，左对齐且未换行、缩小或旋转的单格文本可向右借用相邻空格。遇到有值、公式或合并格时停止。原格横向滚出后，同一窗格内可见的文字尾部继续绘制，原格从视口的单元格列表移除。打印受显式区域、分页和纸面边距约束。[ONLYOFFICE 文本溢出宽度](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/view/WorksheetView.js#L10001-L10046)

编辑会关闭旧预览，隐藏网格不再触发布局失败。参数草稿在普通命令繁忙时保持可编辑，提交仍等待队列，组合输入和文档切换继续阻止操作。

各区域沿 ONLYOFFICE 当前页序先向右再向下，沿行列边界分割。打印切口继续读取相邻可见格的边框，按原优先级保留颜色、线宽及端点；隐藏行列按区间跳过。规则依据[原生分页循环](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/view/WorksheetView.js#L3580-L3611)、[共享边选择](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/view/WorksheetView.js#L7508-L7529)及[页边相邻格](https://github.com/ONLYOFFICE/sdkjs/blob/72b0421c0bbf9d01eed9cf14834ae47eb2df1b50/cell/view/WorksheetView.js#L7640-L7670)。无可见格的区域仍生成一页；无可见格的区域仍生成一页，超宽单列、超高单行、跨页/范围/标题边界合并、未计算公式、未支持显示或未呈现内容明确拒绝。网格和打印共享字体与尺寸，缩放在核心有序图元中完成。屏幕滚动、缩放和 DPR 不改变打印布局。区域与工作表共用整次输出预算，不为每个区域重置。更多纸张/布局变体继续实施。标题计入轴和单元格上限，标题与页眉页脚都计入每页文字上限。
