# P5 XLSX 网格、计算与编辑

状态：`planned`，2026-10-14。本方案基于已完成的 [P2 文件底座](implemented/p2-format-foundation.md)、[P4 编辑交付](implemented/p4-docx-editing.md)和 [R0 通用渲染架构](implemented/r0-renderer-foundation.md)。当前 `modules/formats/src/xlsx` 仍为占位包；以下是待实现范围，不是已有能力。

## 用户结果与首版范围

开发者可以嵌入 XLSX 编辑器，打开真实工作簿，切换工作表，编辑单元格并看到公式更新，撤销后恢复原值，再保存重开。用户可以将当前表的选定区域导出为可打印 PDF。

首条操作链采用简单明细表：修改数量，单价与数量相乘得到小计，`SUM` 得到合计，另一工作表引用合计。输入、计算、显示和保存必须指向同一工作簿版本。

| 能力 | 首版交付 |
| --- | --- |
| 打开与查询 | Transitional `.xlsx`；工作表列表与切换；按地址或矩形查询稀疏单元格；识别共享字符串、内联字符串、数值、布尔值、错误和公式 |
| 网格显示 | 行列标题、滚动、缩放、选区；读取行高、列宽、隐藏行列、基本样式和合并区域；只为当前视口输出绘制与语义数据 |
| 编辑 | 点击与键盘定位、单格输入/清空、矩形清空、纯文本复制/粘贴、撤销/重做；支持组合输入与单元格草稿提交/取消 |
| 计算 | 下文明确的公式语法、六个函数和依赖重算；区分公式源码、导入缓存与本次计算值 |
| 保存 | 已有工作簿中的值/公式修改；保留非目标单元格、样式、未知内容和其他部件；支持无编辑保存与保存后重开 |
| 基础打印 | 当前工作表的一个矩形，按纸张、方向、边距和固定 100% 比例分页；预览与 PDF 使用同一核心打印布局 |

本期从已有文件进入，不新增空白工作簿向导、工作表增删改名或行列插删。样式编辑、自动填充、公式复制改写、排序筛选、冻结窗格交互、条件格式、图表、透视表、图片编辑及协作留待具体需求。XLS/XLSB/XLSM、Strict、加密和签名改写不进入本期支持面。

只覆盖 Chrome/Chromium，沿用现有输入法。Windows/Excel、其他浏览器和 VoiceOver 验收不作为本期条件。

## 单元格、样式与保真

### 状态与读取

MoonBit 的 XLSX 会话持有源 OPC/XML，并从中派生单元格索引、选区、历史、公式依赖和显示结果。源片段与派生索引在同一事务提交；TS 不维护另一份工作簿模型。

位置使用工作表身份、行和列。工作表身份来自包内关系，不使用当前标签顺序作为身份。空单元格、空字符串、零、布尔值和公式错误分别表示。公式源码、缓存结果和计算状态分别返回，不能仅暴露一段显示文字。

工作表按实际存在的单元格存储。`dimension` 只作声明信息，不能按它分配整张矩阵。先校验地址、重复单元格、共享字符串/样式索引和关系，再构造索引。隐藏工作表和行列仍参与计算，不因视口不可见而丢失数据。

### 显示与编辑边界

首版读取单元格级字体、字号、粗斜体、文字色、纯色填充、实线边框、水平/垂直对齐及换行。字体选择、列宽单位换算、文字塑形和裁剪在核心完成。使用文件声明的行高/列宽和默认值，不增加自动调整行高/列宽引擎。

数字格式先覆盖 General、整数、两位小数、千分位、百分比，以及 `yyyy-mm-dd`、`hh:mm:ss` 及对应内置格式。日期继续保存为数值，按工作簿的 1900/1904 日期系统解释；不得经过宿主时区转换。1900 闰日兼容规则依据独立参考落实。其他格式保留原声明，以原始值和明确诊断展示，不能声称显示等价。

合并区域按锚点显示和编辑单格内容；矩形写入碰到合并区域时整体拒绝，避免覆盖隐藏值。受保护工作表、含富文本或未支持编辑语义的单元格保持只读。条件格式、绘图等未呈现内容给出诊断，相关 XML 和关系继续保留。

键入 `=` 开头的内容进入公式解析，前导单引号允许输入文字。数值与布尔值识别由核心处理；日期自动识别和地区化输入推断延后。复制由核心将显示值序列化为纯文本 TSV，粘贴只写值；其中 `=` 开头的字段保存为文字，不自动执行公式。CRLF/CR 统一为 LF，明确处理字段内换行及引号，非法或超预算输入整体拒绝。剪切移动和保留公式/样式的复制留待后续。

### 修改与保存

值修改复用 XML 源补丁。缺少目标行或单元格时，按格式顺序插入必要节点；清空内容保留样式。新写入文字使用内联字符串，不原地修改被其他单元格引用的共享字符串条目。保留原共享字符串顺序，同步必要的计数元数据。

保存只修改目标源片段、受影响公式缓存及必要包元数据。源公式、值类型和缓存结果必须一致。编辑使已有 `calcChain` 失效时，在同一候选包中移除该部件及对应关系/content type，并设置下次打开重算所需的计算属性。只有首次用到时，才给现有 OPC writer 增加必要的部件删除能力。

无编辑保存保留所有部件的原解压后字节。计算缓存可以留在内存供预览使用，不因打开文件就重写源包。保存检查 ZIP/XML/OPC 完整性；失败不返回部分成功文件，也不破坏已提交会话。保真声明沿用 P2 的部件/内容边界，不承诺整个 ZIP 字节一致。

## 公式与依赖计算

| 项目 | 首版约定 |
| --- | --- |
| 语法 | 数值、字符串、布尔常量；括号、一元正负、`+ - * /` 和比较运算；函数调用 |
| 引用 | A1 单格、矩形范围、相对/绝对/混合引用；本表与显式命名的另一工作表；正确处理带空格和引号的表名 |
| 函数 | `SUM`、`AVERAGE`、`MIN`、`MAX`、`COUNT`、`IF`；以固定上游的类型转换、空值、错误传播及 IF 分支规则为依据 |
| 共享公式 | 读取锚点与范围，按相对/绝对规则派生各格公式。编辑命中共享组时，有界地展开受影响组为普通公式，保留其他组和单元格样式 |
| 错误 | 除零、非法类型等是公式结果，不等同于事务失败。语法错误、越界引用、预算耗尽或新建循环依赖拒绝提交 |
| 暂不计算 | 名称引用、结构化引用、外部工作簿、整行整列/三维引用、数组与动态数组、易变函数、迭代计算及未列出的函数 |

核心解析公式并登记单元格依赖及矩形范围依赖。首次打开在预算内计算支持的公式；修改时更新依赖，标记受影响公式并按依赖顺序重算。范围依赖保留矩形，首版可扫描已有范围记录，不展开成整张表的逐格边，也不预建空间索引或通用计算调度框架。

值、公式源码、依赖、计算结果及历史原子提交。撤销/重做恢复对应源内容，并重新得到一致的依赖与结果。一次矩形粘贴形成一个事务；计算失败不能留下部分写入或半新的公式缓存。依赖分析按声明引用处理，IF 的未选分支不求值。

导入缓存只代表文件保存时的结果。存在未支持公式、无法可靠解析的依赖或原有循环时，首期整个工作簿只读；允许查看标记为导入缓存的值和无编辑保存。没有缓存时显示“未计算”，不得当作零。新输入未支持公式直接拒绝。此边界避免在未知依赖下接受编辑后仍显示旧结果，后续有实际需求再缩小保护范围。

公式不触发网络访问、宏或宿主脚本。计算使用有界 token、解析深度、引用、依赖、访问单元格数及工作量；数值预算在实现相应操作时纳入现有预算接口，不另建资源框架。

## R0 接入与 Web 呈现

### 视口由核心生成

XLSX 核心接收工作表、逻辑滚动位置和视口尺寸，计算可见行列、单元格几何及命中位置。行列度量保持稀疏，不按格式最大坐标分配数组。首版滚动覆盖已用区域及有界空白扩展，定位新单元格时按预算扩展。

核心输出 R0 的 point 坐标绘制区域、资源引用和独立的单元格语义。视口结果绑定工作簿 revision 和布局身份；切表、滚动、尺寸、字体或显示依赖变化使旧几何失效。选区移动只更新覆盖层，编辑按受影响结果使当前视口失效。首版允许重绘整个可见区域，不传输或绘制整张工作表。

### 复用现有实现，移除 DOCX 假设

现有 [CanvasRenderer](../packages/web/src/drawing.ts)已经执行通用指令。[PageCanvas](../packages/web/src/page-canvas.ts)仍通过 DOCX Flow 收集图片，并接受包含段落语义的 `PageLayout`；它不能直接充当 XLSX 宿主。

P5 接入时，把实际共用的画布尺寸、DPR、覆盖层、绘制身份及平台资源释放从 DOCX 页面接入中分离。DOCX 保留自己的图片准备与分页语义，XLSX 提供网格语义。两者调用同一个 Renderer，不新增处理表格业务的 `SpreadsheetRenderer`。

纯绘制合同中的 `DrawingBatch.pages` / `drawPage` 在接入时统一为区域命名，DOCX 的真实分页信息继续由 DOCX 拥有。同步修改 Bridge、WASM 校验、Worker、预览、编辑器及相关检查，删除旧字段和调用路径，不保留未发布 API 的别名兼容层。

现有矩形、字形批次和裁剪指令足以作为首版入口。某种基本边框确需新绘制操作时，只补具体操作与实际后端，不引入场景树、指令插件或格式分支。公式、格式化、命中与打印规则始终留在核心。

### Web 针对性处理

Web 使用固定视口大小的内容 Canvas 与覆盖层。按动画帧合并滚动/缩放的呈现请求，丢弃过期呈现结果；已接受的编辑命令仍顺序执行。核心复用成功的计算、文字和几何结果，Renderer 复用会话内字形路径，画布尺寸不变时不重设 backing store。

原生输入元素承载单个未提交草稿与组合候选，TS 处理焦点和平台事件，核心决定解析与提交。双击或 F2 进入单格编辑；Enter/Tab 提交并移动，Esc 取消，离开单元格或切表前先提交。IME 结束只更新草稿，不单独生成工作簿历史。草稿编辑保留原生文字选择与撤销；退出单格编辑后，撤销/重做操作核心工作簿历史。

保存/打印先提交有效草稿，再等待编辑和计算队列屏障。组合未结束时返回明确的编辑未完成状态。解析或计算失败保留草稿与旧值，用户可以修正或取消；revision 冲突不能覆盖外部修改。

为活动单元格及可见范围提供有界的网格语义、地址、值和只读原因，保留键盘导航和焦点恢复。Canvas 像素不作为无障碍内容来源。复用现有队列、错误、关闭和输入事件机制，不复制 DOCX 的段落编辑逻辑。

本期不增加多 Worker、OffscreenCanvas、GPU、跨线程共享内存或自定义二进制协议。出现阻断使用的绘制/传输问题时，沿 R0 合同做最小调整。

## 基础打印与 PDF

默认打印当前表的有内容矩形，也允许调用方指定一个矩形范围。核心按明确的纸张、方向、边距和 100% 比例，沿行列边界分页；超出单页的区域向下再向右输出。空表输出一张空页，单行/列大于可打印区域时明确拒绝。首版不自动套用文件中的复杂打印设置；保留其源内容并告知本次使用的打印参数。

屏幕与打印复用单元格值、格式化、字体度量和绘制操作，打印布局独立于屏幕视口、滚动和 DPR。PDF 从完整打印区域计算，不能截取当前 Canvas。合并区域若跨越首版不能处理的分页边界则拒绝输出，不静默裁掉内容。

复用现有核心 PDF writer 的字体嵌入、文字映射、图形和输出预算。它当前使用 DOCX 布局输入；在 XLSX 首次接入时抽出实际共享的定位文字与页面输出数据，不把工作表伪装成 DOCX 段落。R0 的轮廓指令不能代替 PDF 所需的 Unicode、glyph 和字体信息。

打印范围包含未计算公式、未支持显示格式或未呈现对象时，返回具体原因，不生成貌似完整的 PDF。打印设置修改、重复标题、手工分页、适配页数及整本工作簿打印留待后续。基础打印交付以 PDF 为准，不依赖浏览器 DOM 打印或新的 PDF reader。

沿现有四个 MoonBit module 和两个 TS 包实现。XLSX 与 DOCX 各自拥有会话，同一套 Worker 调度按已打开会话处理请求；不预建格式插件注册表或新的发布包。格式专属 API 在所属文件导出，共享修改同步更新全部调用方，并遵守源码文件 800 行上限。

1. 完成值文件的打开、单格修改与保真保存。
2. 接入 R0 视口，完成切表、定位与键盘输入。
3. 加入首批公式，串起跨表依赖与历史恢复。
4. 完成矩形粘贴、组合输入和失败恢复。
5. 接入核心打印布局与 PDF，补齐操作说明。

每步交付可运行入口和对应输出。首条可见操作链完成后逐项扩展，不先重构所有通用模块。共享绘制与 PDF 变更直接检查受影响的 DOCX 路径，不要求重做 P4 全量验收。

## 足够检查与完成条件

本次仅制定方案，没有 XLSX 运行结果。优先从固定上游挑选简单值/样式工作簿和公式工作簿；按内容身份入库，登记许可、来源、操作与独立预期。已有 DOCX/PDF 工具继续复用，XLSX 输入准备完成不等于 SDK 通过。

| 用户操作或实际风险 | 足够的检查 |
| --- | --- |
| 明细表编辑、重算与历史 | 使用独立算出的值及固定参考结果，验证同表/跨表依赖、共享公式、错误传播、撤销和重做；不由 SDK 生成预期 |
| 保存重开与非目标保留 | 用独立 ZIP/XML 检查值类型、公式/缓存、必要元数据及非目标部件；新 SDK 会话与一个参考应用分别重开 |
| 真实网格输入 | Chromium 操作切表、滚动、选择、输入、组合提交/取消和矩形粘贴；确认保存结果、键盘焦点与可见语义 |
| 拒绝与恢复 | 将未支持公式、循环、受保护范围、过期状态和一次超预算粘贴纳入上述操作；检查没有部分提交，修正后可以继续；关闭释放沿现有用例扩展 |
| 打印与共享改动 | 检查非当前视口内容、多页边界、文字/数值及基础样式；复用 qpdf/Poppler；按实际改动挑选 DOCX Canvas/PDF 保留用例 |

解析边界和计算规则用小型定向用例补足具体风险，不给每个函数和格式组合铺验收矩阵。保留文件、单元格/文字、公式工作量、历史、队列、输出与 Canvas 预算，超限原子拒绝；不因只渲染视口而放宽文件解析或计算上限。

完成条件是范围内真实工作簿能从嵌入入口完成打开、编辑、计算、撤销、剪贴板、保存重开和打印 PDF，非目标内容保留，关键拒绝与恢复有证据。API、支持面和限制更新到[开发说明](references/development.md)与[格式合同](references/formats.md)后，再按规范归档。

按[测试说明](references/testing.md)运行直接覆盖变更的检查，通过后交付。仅当局部检查覆盖不了明确的跨功能风险时扩大运行。性能专项、海量工作簿压测和发布验收延后；实际卡死、无法交互或资源失控时再诊断。
